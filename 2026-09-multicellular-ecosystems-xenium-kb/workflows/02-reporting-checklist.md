# W02｜研究报告与审稿检查表（TRANSFER）

## 设计与数据

- [ ] 患者/动物、标本、切片、ROI 和细胞的关系明确；独立重复数与细胞数分别报告。
- [ ] 分组定义、批次、配对、病理构成和缺失数据可核查；没有把多个切片当新动物。
- [ ] 面板版本、RNA 特征过滤、程序覆盖与关键缺失节点已报告；未测量与零计数分开。
- [ ] 关键 ROI 的分割、分子归属、坐标配准和空间质量已核查；是否重分割如实记录。

## 方法与统计

- [ ] 细胞身份、细胞内状态与 ROI 组成分开；不确定注释保留。
- [ ] 空间图、距离定义、边界和组织空洞处理明确；主尺度与探索尺度区分。
- [ ] 零假设与交换性合理；组别检验没有置换不独立的全体细胞。
- [ ] 比例、检测密度和空间效应不混用；效应量、区间和逐样本结果齐全。
- [ ] 样本内与样本间状态关联区分；随机效应不被当作空间依赖的万能修复。
- [ ] 多重比较包含声明的探索范围；没有只报告最显著半径或最佳聚类。

## 验证、图和措辞

- [ ] 验证终点没有参与定义 niche 或分组；训练/测试按合适生物学单位分离。
- [ ] 原始分子证据与预测表达分开；通讯分数没有被写成因果。
- [ ] 图例说明数据类型、样本数、空间尺度和零模型；教学图明确标注非实测。
- [ ] RNA 的 ECM 程序没有代替沉积、排列或力学验证；病理结构与功能区分。
- [ ] 失败、阴性、未执行、未测量四种状态没有混淆。
- [ ] 所有来源和方法参数能追溯；科学复现与知识库工程测试分别报告。

建议结论模板：**在 N 个独立样本中，我们观察到……；在指定区室和协变量条件下……；仍不能排除……；下一步需要……来区分这些解释。** 不填未知 N，不杜撰 p 值、效应或治疗获益。
