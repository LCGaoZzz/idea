# M04｜从通讯候选到机制，而不是从网络图到因果

## EXTERNAL_FACT：方法输出的层级

LIANA+ 提供多种单细胞/空间通讯推断组件；NicheNet 将候选配体与接收细胞靶基因联系。[R09](https://pubmed.ncbi.nlm.nih.gov/39223377/)；[R10](https://pubmed.ncbi.nlm.nih.gov/31819264/)

## ANALYSIS：网络边不是独立验证

配体和受体转录本共表达、数据库支持与空间邻近，可以共同提高候选关系的合理性，但仍可能受共同刺激、细胞组成或分割影响。受体 mRNA 不等于活性受体，靶基因评分也可能受其他通路驱动。固定物理半径不适用于所有分泌、接触、基质结合和间接作用。

## TRANSFER：给每条候选轴留证据空格

| 证据字段 | 要回答的问题 |
|---|---|
| sender / ligand | 发送端身份是否可信，配体是否实测？ |
| receiver / receptor / complex | 关键亚基是否覆盖，是否有接收能力的其他证据？ |
| spatial_context | 在哪种病理区室和距离上成立，是否超出组成效应？ |
| receiver_response | 是否有方向合理且未用于循环定义的接收端反应？ |
| replication | 多少独立样本支持，是否被单个样本支配？ |
| alternatives | 共同驱动、技术错配、病理区室等解释是否仍成立？ |
| perturbation / function | 干预是否改变目标关系及独立功能？本版均未执行。 |

没有覆盖受体亚基，就写“未知/未测量”，不要写“通讯关闭”。所有候选都给明确缺口，不让综合分数掩盖缺失环节。

## TRANSFER：用设计区分解释

在获得初步证据后，选择能区分竞争解释的干预：既测发送/接收状态，也测组织结构和独立功能。时间先后、特异性、替代解释及补救证据可增强机制论证，但任何单一结果都需要结合干预本身的多效性和模型适用范围。

结论措辞可以逐层提高：“空间伴随”“调整指定因素后的状态关联”“候选信号”“干预支持的机制”。不要在纯观察数据阶段写“驱动”“特异治疗有效”或“已发现必要维持轴”。
