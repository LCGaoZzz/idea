# Agent 问答路由

| 常见问题 | 回答要点 | 读取入口 |
|---|---|---|
| CAF 与巨噬细胞同时增加，是否为生态位？ | 只支持组成共变，需空间和状态证据 | [概念](../knowledge/01-evidence-framework.md) |
| 共定位是否证明通讯？ | 否；还要考虑区室、组成、分割和接收端反应 | [通讯](../methods/04-communication-and-causality.md) |
| 50 个程序基因只测到 3 个，能评分吗？ | 可算不等于可按完整程序解释；报告覆盖和缺失 | [测量](../methods/01-xenium-panel-segmentation-qc.md) |
| 受体没有信号，是否没通讯？ | 区分未测量、实测零、灵敏度和复合体覆盖 | [测量](../methods/01-xenium-panel-segmentation-qc.md) |
| 十万细胞是否有很高统计功效？ | 看真实生物学重复和估计目标，不用细胞数冒充样本数 | [统计](../methods/03-statistics-and-spatial-nulls.md) |
| DIALOGUE 和 CoVarNet 有什么区别？ | 协调表达程序与跨样本丰度协变，不是同一目标 | [方法选择](../methods/02-niches-and-coordination.md) |
| CoVarNet 是否必须排除上皮？ | 原论文跨组织分析如此，不能外推为所有肿瘤分析通则 | [方法选择](../methods/02-niches-and-coordination.md) |
| 更大的空间 Z-score 意味作用更强？ | 不一定，需可比较效应量与相同零假设 | [统计](../methods/03-statistics-and-spatial-nulls.md) |
| Tlow 的 T 细胞少是否验证免疫抑制？ | 若按 T 数定义组别，则属于循环验证 | [应用](../applications/01-caf-myeloid-tumor-niche.md) |
| 三时期样本能否重建真实谱系？ | 可提出阶段演进假说，不能仅据横断面声称真实谱系 | [时序](../applications/02-temporal-and-cross-cancer-transfer.md) |
| 方法都跑一遍并取一致结果是否更强？ | 共享偏差会产生一致；需独立证据和问题匹配 | [方法选择](../methods/02-niches-and-coordination.md) |
| 这套库已经复现了论文吗？ | 没有；本版是带来源的研究知识库和读取工具 | [范围](../evidence/reading-scope-and-gaps.md) |
