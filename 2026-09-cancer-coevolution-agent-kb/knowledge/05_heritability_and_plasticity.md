# 05｜遗传性与可塑性：一个相关结构问题，而不是一句形容词

**论文框架：[S04]；代码语义：[S13][S14]；公式推导和限制讨论标记为 ANALYSIS。**

## 1. “遗传性”在这里应先理解为谱系持续性

PATH 将细胞状态与谱系上的亲缘结构联系，用系统发育相关衡量状态的持续性，并在模型约束下推断动态。[S04]

这和数量遗传学中把表型方差分为遗传方差、环境方差后给出 h² 并非天然同一个估计量。近亲细胞状态相似，可能包含遗传变异效应，也可能包含传递的表观记忆、共享局部环境或未建模的技术结构。

最稳妥的报告句式是“在给定树、状态定义和取样条件下检测到谱系相关”，而不是“证明此表型由基因决定”。

## 2. 通用 Moran's I 的教学推导

对 n 个细胞的连续表型 x，令 zᵢ=xᵢ−x̄，权重矩阵 W 的 wᵢⱼ 反映细胞关联，wᵢᵢ=0。定义：

`I = [n / Σᵢⱼwᵢⱼ] × [Σᵢⱼ wᵢⱼ zᵢzⱼ / Σᵢzᵢ²]`。

分子问“被赋予大权重的细胞对是否倾向于同高或同低”；分母把尺度标准化。W 的定义就是问题定义的一部分：姐妹细胞权重、多个祖先深度的权重、或其他距离转换，问的是不同时间/亲缘尺度的持续性。

在非自身权重、固定 W、对标签可交换随机置换的常见零假设下，`E[I]=−1/(n−1)`，不是严格的 0。期望公式不应在不满足交换性的分层样本上机械使用。

I 并非普遍被限制在 [0,1]，也不是“有百分之 I 的遗传贡献”。因此 `1−I` 不能无条件当成通用可塑性比例。`x` 为常数时分母为 0，统计量未定义；它不是“可塑性最高”或“遗传性最低”。

本库 `tools/demo.py::moran_i` 实现的是上述通用教学统计量，**不是 PATH 的完整相关、显著性或动力学实现**。

## 3. 概率标签与硬标签

状态往往来自表达聚类或分数阈值。两个阈值两侧的相似细胞被强行视为不同状态，可以人为增加表面上的转换。先检查连续分数、离散标签置信度和阈值敏感性，再解释动力学。

一棵树几乎全是同一状态时，缺少的是区分状态持续性的变异信息。增加一万个同状态细胞不一定解决这个问题；需要足够状态差异且谱系位置有辨别力。

## 4. 从静态相关到动态需要加假设

高相关可能来自低切换速率，也可能来自选择优先扩增了某种状态，或新近共同环境影响了一个局部支系。低相关可能来自真实状态流动，也可能来自状态测量噪声、错误树或稀疏取样。PATH 原文的取样分析也提醒了采样对相关性的影响。[S04]

因此，要把“低谱系相关”升级为“高细胞内在可塑性”，应同时检验状态可靠性、谱系分辨率、采样深度和环境共变。能做空间约束或多尺度敏感性分析时，应解释它们各自削弱了哪种竞争解释。

## 5. 显著性不是效果大小，更不是因果性

极多细胞可以让很小的相关偏离具有小 p 值；细胞嵌套和图依赖又可能使简单零假设不合适。报告应同时给出相关大小、状态占比、独立生物样本数、树/标签敏感性和显著性校准方式。

审读 `xcor.R::xcor` 时，发现其返回名 `one.sided.pvalue` 对应计算 `2×Φ(−|Z|)`，这是双侧正态尾概率。此处是可定位的接口语义不一致，不等于我们已经证明论文结果错误；下游是否使用这一字段还需核验。[S13]

**自测**：若一个甲基化定义的状态在同一批甲基化位点构出的树上高度聚集，最先需要排除什么？回答应涉及状态读数和历史读数是否共享了定义证据。
