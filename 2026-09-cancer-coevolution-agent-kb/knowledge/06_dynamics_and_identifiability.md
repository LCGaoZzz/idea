# 06｜状态动态：为什么一张比例图不足以说明转换

**层级：ANALYSIS。数学例子为本库原创教学模型，不冒充 PATH 或综述的完整推导。代码审读对应 [S14]。**

## 1. 两状态反例：完全相同的比例，完全不同的速度

令 A→B 的连续时间速率为 a，B→A 为 b。取行向量约定：

`Q = [[−a, a], [b, −b]]; P(t)=exp(Qt)`。

平稳分布是 `π_A=b/(a+b)`、`π_B=a/(a+b)`。当 (a,b)=(0.05,0.05) 和 (5,5) 时，两者平稳比例都是 50%/50%，但单状态平均停留时间分别为 20 和 0.2 个时间单位。

因此“状态构成没有变化”既可能意味着稳定继承，也可能意味着快速来回转换抵消。不能仅凭不同时期比例相近，就断言“细胞状态稳定”。

从 A 出发的概率有解析式：

`P_AB(t)=a/(a+b) × [1−exp(−(a+b)t)]`；
`P_AA(t)=b/(a+b)+a/(a+b) × exp(−(a+b)t)`。

本库程序检验两行概率和为 1、t=0 为单位阵、平稳分布保持不变，并对快慢模型实际计算。

## 2. 转换与选择如何同时改变比例

设 n 为各状态数量的行向量，r_s 为状态 s 的净增长率。一个简化模型为：

`dn/dt = nQ + n diag(r)`。

令 p_s=n_s/Σᵣn_r、r̄=Σᵣp_r r_r，则：

`dp_s/dt = Σᵣ p_r q_rs + p_s(r_s−r̄)`。

第一项是转换，第二项是差异增长。两种机制都能改变状态比例。若只看到 p 的有限时间点，许多 Q 与 r 组合可给出近似相同的路径。即使观察总数量，出生与死亡的分离通常还需要额外信息。

这个模型把净增长当作简化变量；并不声称所有真实细胞群都满足常数速率、时间齐次或无密度依赖。模型是为了澄清“要估计什么”和“观测限制什么”。

## 3. 谱系增加的是哪种信息

除了边际状态比例，树提供相近祖先后代的联合状态模式，以及在不同分支尺度上的相关结构。同样的总比例，若相邻后代经常保持同状态，与相邻后代频繁出现不同状态，支持的动态解释不同。

但若分支时间、取样机制或状态测量不可靠，树也不是自动的万能信息源。多起点拟合只能帮助识别数值优化问题，不能修复结构性不可识别。

## 4. PATHpro 的真实实现语义

在已读的固定版本中，`PATHpro.XW` 从状态矩阵及权重矩阵得到细胞对频率，并进行对称化；`PATHpro_loss` 将 Q 与增殖项合并，利用矩阵指数产生模型期望的细胞对频率，再加转换率惩罚；拟合由 `fitPATHpro` 调用 `nlminb` 完成。[S14]

代码返回的 `P=exp(Q)` 是一个分支尺度时间单位的转换概率矩阵。Q 的单位取决于输入树的分支单位。未提供总增殖约束时，代码将估计增殖量减去最小值，因此其 gamma 是相对量；不能解释成绝对每天增殖率。[S14]

进一步的研究建议是：报告多个优化起点、目标函数分布、参数不确定性和树尺度敏感性；对没有被数据识别的参数保留区间或等价模型，而不是只保留最优一次的漂亮矩阵。这些建议不是已经执行的 PATH 复现。

## 5. 时间缩放的不变性

若只有 `Qt` 进入观测概率，则把时间乘 c、同时把 Q 除以 c，P(t) 不变。没有外部时间锚点，所谓“每天转换率”便没有唯一答案。

这也是为什么“加一个 t=1 标签”不能完成时钟校准。t=1 只是单位约定，必须问它究竟代表一条标准化树长度、一次分裂、一天还是其他量。

## 6. 可识别性优先的研究输出

先列出每个参数的单位和观测来源，再做模拟恢复：用已知参数生成与真实采样规模相似的合成数据，测试能否恢复且区分相邻候选模型。若不能，不应靠增加显著性符号来补救。

建议同时输出“观察支持”“模型依赖”“需要额外实验”三层结论。例如观察支持状态与谱系相关；模型依赖的结果是特定 Q；需要额外证据的是环境是否直接控制 Q 中某个方向。
