# 03｜内源谱系标记：选择能回答问题的记忆介质

**来源背景：[S06][S08][S09]；以下比较为 ANALYSIS/TRANSFER，不是综述完整技术清单。**

谱系标记的作用是给细胞间的历史关系提供信息，而不是必须直接驱动表型。一个无明显功能效应的乘客变异，可能是很好的祖先标记；一个强驱动变异，也可能因为反复独立发生而不足以唯一标识祖先。

## 1. 核基因组单核苷酸变异

可观察的共享变异模式支持共同祖先，但解释取决于检出误差、覆盖度、是否可能同位点重复发生、细胞中是否漏检。只有树拓扑，没有可靠分支长度，通常更适合回答亲缘关系，而非起源于多少年前。

“共享一个热点突变”与“共享同一整套变异组合”包含不同的信息。仅凭一个热点位点，把所有阳性细胞认作完全相同的终末克隆，会掩盖进一步亚克隆结构。

## 2. 拷贝数改变与 WGD

CNA 描述片段或染色体的拷贝变化。与单个离散 SNV 不同，大片段事件可相互重叠，发生丢失、加倍或后续改写。MEDICC2 针对单倍型分辨的拷贝数演化与全基因组加倍构建树，明确面对更复杂事件历史。[S06]

把分段拷贝数向量做欧氏距离和层次聚类可以得到探索性分组，但距离不自动代表“经历了多少个演化事件”。如果要把分支解释成事件历史，必须交代用于距离计算的演化模型、倍性和分段不确定性。

WGD 后 copy=2 未必等于原始正常二倍体背景；total-copy 相同也可能有不同等位构成。需要把相对值、绝对拷贝数和单倍型状态分开。

## 3. 线粒体变异

Ludwig 等的原始工作展示了从单细胞组学中的 mtDNA 变异提取人类天然谱系信息，并关联转录或可及性表型。[S08]

教学上的关键不是“线粒体更好”，而是它提供了不同于稀疏核基因组覆盖的标记通道。标记可检出性、细胞类型差异和异质性比例变化仍需处理。作为工作假说，应检验同一克隆标记是否在不同组织/状态中有一致支持；不要仅凭 mtDNA 变异与状态相关，就将其解释为该状态的驱动机制。

## 4. 随机表观突变与状态性甲基化

EPI-Clone 利用甲基化信息中的不同成分区分细胞身份与克隆标记：并非所有 CpG 的变化都承担同一种角色。[S09]

这提供了普适提醒：同一种组学既可以是表型读数，也可以是历史读数，区别在所用位点的生物学行为与选择策略。若用强状态响应 CpG 构树，再用同一批 CpG 证明状态高度遗传，可能形成自证循环。

跨供体“批次效应”也不能机械处理。若某变异模式真正包含个体克隆历史，强行全部对齐会消去想要研究的信号。反之，把所有供体差异都认成克隆历史也不合理。需要设计上区分技术重复、供体和谱系来源。

## 5. 选择矩阵

| 问题 | 优先核对的标记性质 | 常见误读 |
|---|---|---|
| 识别已知突变群体 | 靶位点特异性和分型成功率 | 未检出=野生型 |
| 重建较细祖先关系 | 足够可区分的多位点历史信息 | 单个共享热点=完全相同克隆 |
| CNA 演化事件 | 片段、倍性、单倍型、WGD 模型 | 聚类距离=事件数 |
| 跨状态克隆追踪 | 标记相对独立于当前状态 | 状态相同=亲缘相近 |
| 起源时间 | 已校准变异过程与采样时间 | 分支长=存活时间长 |

最重要的不是标记数目大，而是“对于目标时间尺度和细胞背景，它们增加了什么可识别的信息”。
