# 00｜先确定我们究竟知道什么

**层级：证据登记与阅读边界。**

目标文献是一篇综述，不是一项新实验的 Results+Methods 报告。其价值在于把基因型、细胞状态和谱系问题组织到同一研究视角。本次可核验的目标来源范围写在 [S01]；不能把另外十篇原始论文读到的内容算作“综述正文已读”。

## 三种不同的“不知道”

第一种是**访问缺口**：正文或图注不可得。此时只能保留问题，不能用领域常见方法补成作者实际写法。

第二种是**实现缺口**：我们看到了论文描述，但没读相应代码、配置或最终调用。此时“论文声称采用”与“代码确实如此执行”是两个状态。

第三种是**可识别性缺口**：即使数据和代码都有，观测也可能不能区分多个机制。例如相同状态比例可能来自完全不同的切换速率。这不是检索更多文献即可消除的问题，要增加可区分机制的观测或约束。

这三个缺口必须分别报告。把访问缺口说成算法不可靠不合理；把数学不可识别当成调参没做好同样不合理。

## 本版能回答的与不能回答的

本版可以解释代表性方法测到了什么、推断了什么、依赖什么前提；可以定位两个 PATH 核心 R 文件的真实计算语义；可以用可执行反例说明状态、谱系与速率的差别；可以为新项目产生能力边界与补证清单。

本版不能提供目标综述逐节忠实转述、完整图注翻译、全部参考文献评议、未公开参数表，或任何真实患者数据的分析结果。统计教学公式全部按 ANALYSIS 标注。作者代码只按 CODE 标注，阅读不等于执行。

## 来源如何追溯

每条论断有稳定 ID。`source_id` 指向文章或固定代码文件；`locator` 优先使用 Abstract、明确的方法小节、文件路径及函数名。没有拿到页码和行号时就不用页码和行号，不能编一个精确定位来增强可信度。

图只记录可见主题；完整图注缺口是 G02。正文缺口是 G01。对于 EPI-Clone、Numbat 等概念补充，引用登记明确写 external，不暗示它们一定出现在目标综述引用表中。[S07][S09]

## 升级到全文核验版的操作

拿到合法正文后，保持旧论断 ID 不变。新增来源版本、文件哈希和页码定位；逐项标记 supported、qualified、contradicted 或 unresolved；把受到影响的解释和迁移建议一起重审。不能只把“全文已获取”字段改成 true，而不逐条核验旧知识。最后更新 change log、问答评估与校验和。

完整性应按具体覆盖对象报告，例如“摘要和图题已核验、正文未核验”，而不是虚构一个 85% 完成度。
