# 02｜测量层：直接共测、计算连接与表达代理

**原始方法事实在 [S02][S03][S05][S07][S11]；其余为 ANALYSIS 或 TRANSFER。**

## 1. 三条证据路径不能混为一谈

G&T-seq 将一个细胞的基因组 DNA 与全长 mRNA 分离并分别测序，提供直接的同细胞连接。[S11]

GoT 把靶向基因分型与液滴单细胞转录组联系起来；GoT–ChA 将靶向基因型与染色质可及性联系起来。[S02][S03]

TreeAlign 则把独立采集的 scDNA 与 scRNA 通过模型进行连接。它不是“把两种分子从同一个细胞实验共测出来”。[S05]

Numbat 使用转录组的表达和等位基因信息推断 CNA 与克隆，是遗传信息的统计推断，而非直接单细胞全基因组检测。[S07]

这些路径没有单一的总排名。真正要比较的是当前问题需要的证据强度、可获取输入、偏差来源和可验证程度。

## 2. “没有突变 reads”为什么不等于野生型

考虑一个仅用于教学的模型：在一个已知杂合突变细胞中，每个独立、可用分子的突变等位基因概率为 p，观察了 m 个分子。则：

`P(没有突变分子 | 该细胞实际携带突变) = (1-p)^m`。

若 p=0.5，m=1 时漏见概率为 0.5；m=4 时为 0.0625；m=10 时约为 0.00098。m=0 时完全没有该位点信息，绝不是强野生型证据。结果由 `tools/demo.py` 实际计算。

这个公式假设分子独立、等位表达和捕获过程被 p 表示。PCR 重复 reads 不是更多独立分子；等位基因特异表达、技术掉落与比对偏差都可使这个理想模型失效。因此它只能解释逻辑，不能拿来做生产级基因型判定器。

建议数据表明确区分 `mutant / wildtype_supported / unresolved`，保留 alternate_count、total_count、检测置信度、平台与位点。所有阈值由具体模型、阴性样本和误差校准决定，不在此库硬编码“≥3 reads 就突变”等规则。

## 3. 基因型和状态的循环定义

若用某染色体的一批 RNA 表达特征推断 CNA，然后又用同一批表达特征证明“该 CNA 显著提高这些基因表达”，第二步并非完全独立的验证。

可行的缓解思路是：使用独立 DNA 支持；将推断特征和下游验证特征拆分；对不同参考细胞、技术噪声和克隆置信度做敏感性分析；明确把无法消除的共享证据记为限制。拆分特征本身也不必然完全独立，因为同一染色体内有相关结构。

## 4. 同细胞连接仍需要实验身份检查

细胞 barcode 只在其文库命名空间中有意义。需要 `sample_id + library_id + cell_barcode` 的唯一键、分子与细胞层面的双细胞检查，以及每个模态过滤后的交集说明。

计算插补的基因型要单独列出 `genotype_origin=imputed`；真正靶向检出的列为 `direct`。GoT–ChA 的 DOGMA-seq 扩展包含线粒体辅助插补这一细节，正是必须保留来源标签的实例。[S03]

## 5. 可测性本身会制造偏差

设 D 表示位点可被分型。若目标基因的表达受状态影响，那么只分析 D=1 的细胞，可能改变状态构成。应比较被成功分型与未分型群体在细胞背景、UMI、样本、位点表达方面的差异；不能只画成功分型子集的漂亮图。

一个基础 QC 表至少包含每个“患者×背景×基因型来源”的可分型比例，而不只是全局分型率。稀有状态可能恰好是检测最差的状态，这会直接影响基因型—状态效应。

**可迁移结论**：任何多模态研究都应先回答“哪些关系是实测、哪些是推断、哪些是没有信息”，再讨论生物学解释。
