# 方法选型总览

本表按 **已有输入能支持的问题** 选型，不做缺乏共同基准的优劣榜。

| 已有输入 | 候选方向 | 最重要的边界 |
|---|---|---|
| 靶向基因型+同细胞 RNA | M01 GoT | 分型缺失不是野生型 |
| 靶向基因型+同细胞可及性 | M02 GoT–ChA | motif/可及性不是功能验证 |
| 真实同细胞 DNA+RNA | M03 G&T-seq 类配对分析 | 核对实验身份与两模态质量 |
| 独立 scDNA+scRNA+DNA 树 | M04 TreeAlign | 概率连接不是实验共测 |
| RNA+适合的等位/单倍型信息 | M05 Numbat | RNA 推断不是直接 DNA 测量 |
| 单倍型拷贝数状态 | M06 MEDICC2 | 输入分段、倍性与事件模型 |
| mtDNA 变异+单细胞表型 | M07 内源线粒体标记 | 标记功能与历史作用分开 |
| 合适的单细胞甲基化 | M08 EPI-Clone | 状态 CpG 与历史 CpG 不混淆 |
| 已有谱系树+匹配状态 | M09 PATH | 分支单位、采样和状态变异 |
| 只有空间表达与坐标 | 状态和生态位的探索性分析 | 先别声称直接基因型或谱系追踪 |

“候选”不意味着可以立即运行，更不意味适配所有物种或平台。Agent 的 plan 工具只做能力门槛检查，不安装或执行这些作者软件。
