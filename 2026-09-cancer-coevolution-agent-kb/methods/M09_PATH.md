# M09｜PATH

**定位：给定谱系的状态持续性与动态分析。** 与目标综述的关系：目标综述引用 103。

## 原始证据边界

**PRIMARY**：将带有表型的单细胞谱系用于量化相关结构，并推断状态转换及增殖动态。 [S04]

**核验状态**：摘要及方法片段核验；固定版本两个核心 R 文件静态审读，未执行 [S13][S14]。

以下输入审查、假设、失败模式和验证建议是本库的 **ANALYSIS/TRANSFER**；不是作者的完整实验步骤或生产运行配置。

## 输入合同

- 真实谱系证据支持的树
- 匹配树叶的状态向量/特征矩阵
- 解释动态时需要分支单位与采样假设

## 输出应该怎么读

- 系统发育自相关/互相关
- 模型约束下的转换矩阵及相对或有约束增殖量

## 关键前提

树和细胞标签匹配；状态有足够变异；采样、分支尺度和动态模型合适。

## 失败模式

拟时序当谱系、常数特征、低分辨率树、单位缺失、单起点或误读相对 gamma。

## 最小验证

树叶匹配、状态变异、分支尺度、采样与标签敏感性、多优化起点；检查 p 值字段语义。

## 硬边界

无谱系数据不能把常规 UMAP 直接转为 PATH 的祖先树；Moran 教学程序不是 PATH 替代品。
