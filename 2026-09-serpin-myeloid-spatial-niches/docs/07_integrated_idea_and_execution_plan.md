# 07｜完整 idea：稀有恶性状态通过局部材料环境组织免疫保护生态位

[返回总目录](../README.md) · [上一章](06_code_walkthrough_and_audit.md) · [下一章](08_sources_data_and_reproducibility.md)

> 本章是从原文获得的研究设计提炼与拟议扩展，不是作者已经做过的附加实验，也不保证换一个癌种就具有新颖性。真正的新意需要来自新的来源状态、材料机制、作用尺度或可检验的组织规律，而非仅更换疾病名称。

## 1. 研究问题与中心假说

研究问题：在整体平均表达不显著或来源细胞比例不高的肿瘤中，是否存在一类恶性状态，通过局部胞外材料环境组织髓系细胞，改变 T 细胞进入与功能，并为自身及邻近肿瘤细胞提供免疫保护？

中心假说分成四个可独立失败的部分：

**H1 来源稀疏但空间效应可重复。**局部来源暴露比整个肿瘤平均表达更能描述邻域变化。

**H2 材料是可测中介候选。**特定材料状态连接来源与髓系位置/程序，且不只是泛化纤维化的替代标签。

**H3 作用具有跨细胞成分。**改变来源群体会改变未被同样扰动的邻居；混合环境能够产生补偿或共享影响。

**H4 生态位改变参与环境依赖适应度。**这种作用在不同免疫背景或治疗条件中具有不同的群体后果。

四项不是一个必须全部为真的故事模板。任一项失败都应改变结论，而不是通过增加图表强行闭环。

## 2. 为什么这比“候选基因＋免疫浸润相关”更强？

普通相关分析将不同来源、材料与组织结构折叠为一个样本级信号。此 idea 则要求每个连接有自己的测量：来源身份、局部暴露、材料读出、髓系内部状态、T 细胞终点、独立的群体功能。

它还要求区分数量与状态、空间共现与干预、起始分配与终点选择。因此其主要增量是可识别性，而不是算法清单更长。

## 3. 工作包 A：在现有数据中识别来源状态

### 输入

有患者与来源 ID、可解释的恶性细胞注释、原始 counts/非负标准化表达，以及技术质量字段的单细胞数据。候选可以来自已有假说，也可来自预先规定的来源/胞外功能筛选，不将“显著基因越多越好”作为目标。

### 分析

患者内计算来源比例与阳性细胞条件强度，检查双状态/并集及在既有肿瘤亚型中的分布。候选应跨患者存在，而不是由某个患者的大量细胞形成看似稳定的新簇。保存来源细胞数量及检测不确定性；必要时按测序深度或技术质量匹配。

### 交付

`source_state_per_patient.csv`、状态定义文件、每患者细胞数、输入表示说明、全部候选表和排除理由。

### 进入下一阶段的条件

来源身份可信、关键候选被实际测量、有多个独立个体支持可分析性。若只有一个患者或阳性数极少，不直接进入泛化结论，可先作为个案提出假说。

## 4. 工作包 B：把来源状态放回组织

### 输入

明确图像 ID、物理单位坐标、细胞/spot 注释、组织掩膜和患者映射的空间数据。若使用解卷积，保留估计类型和不确定性；若使用靶向面板，先审计基因覆盖。

### 主分析

预先指定主要局部尺度与主要免疫终点。以固定网格、可解释窗口或受体细胞为单位计算局部来源比例、绝对密度和距离。只在同一图像中找邻居，跨图像重用坐标不能产生边。对每个窗口保存有效面积、总细胞/恶性细胞数和重叠信息。

结局至少分开：CD8 密度、CD8 的指定分母比例、CD8 内部功能相关状态；髓系密度与髓系内部程序也分开。

### 验证

同患者匹配区域比较；患者级模型或汇总；合理空间零模型；不同尺度和阳性阈值敏感性；留一患者验证。探索发现的阈值需要新的验证数据。

### 交付

`roi_table.csv`、`roi_exclusions.csv`、`roi_membership` 或可重建索引、组织/窗口 QC、患者级效应和全部敏感性结果。

## 5. 工作包 C：把材料从假说变成实测变量

### 输入与测量

在空间范围匹配的组织中测定指定材料，而不是只做一个宽泛 ECM score。保存材料阳性面积、强度、背景、阈值、组织掩膜以及髓系细胞与材料的相邻/重叠关系。

### 关键比较

来源状态与材料相关吗？同样数量髓系细胞的内部状态随材料改变吗？该关系是否超出总体纤维化、肿瘤密度或位置所能解释的范围？这些调整需要因果假设，不能无条件把候选中介全部调掉。

### 体外分解

采用基底×培养背景的因子设计，先分开材料与可溶性因素。若研究药物，再用材料×药物交互并保留活性、回收和分布。只测平均标志强度不够支持完整功能主张。

### 交付

`matrix_features.csv`、材料测量定义、批次/供体表、技术重复原始表、供体级交互对比及不一致结果。

## 6. 工作包 D：以有限扰动检验跨细胞作用

在已有来源与材料证据之后，再决定是否需要原位扰动。选择能够清晰解释的候选与对照，确保扰动身份、目标效率和细胞表型分别验证。

关注的不只是终点细胞多少，还包括早期邻域变化、源细胞实际组成、未被同样扰动的邻居状态，以及独立/混合条件的差异。混池阴性时先检查邻居补偿、来源不足、作用范围不匹配和读出缺失，再决定是否否定机制。

真实动物、基因扰动与药理实验需要相应伦理、专业人员和方法确认；本目录是研究设计与分析合同，不是可直接替代实验培训的操作手册。

### 交付

扰动—标签映射、目标验证记录、每个独立肿瘤的起始与终点组成、细胞/图像级匹配质量、局部环境终点、肿瘤功能终点和完整阴性结果。

## 7. 如何安排样本量，而不是凭空指定一个数字？

先用先导数据估计患者间差异、组织内相关性、有效来源细胞数和 ROI 重叠。功效或精度规划应模拟“患者—切片—ROI”层级，而不是只计算需要多少万个细胞。

特别是局部显性：需要足够的独立患者在低暴露区提供信息。即使总细胞数很大，若只有一个患者有低比例来源，就不能可靠估计跨患者低剂量规律。

材料因子实验则基于供体级交互的方差规划。更多技术孔主要减少同一供体条件测量噪声，不替代更多独立供体。

## 8. 拟议结果图结构，不是论文原图复刻

| 新研究结果图 | 要回答的问题 | 必须同时展示的约束 |
|---|---|---|
| 图 1 来源状态 | 候选究竟存在于谁、占多少？ | 每患者 n、阳性定义、强度与比例分开 |
| 图 2 空间暴露 | 来源附近是否有可重复邻域变化？ | 尺度、掩膜、患者分层与空间零模型 |
| 图 3 材料连接 | 哪种实测材料与来源和髓系相连？ | 材料测量对象、组织背景及图像 QC |
| 图 4 细胞状态与功能 | 是细胞数量变化还是内部程序变化？ | 指定分母、功能终点与技术偏倚 |
| 图 5 干预与邻居 | 来源被改变后，邻居是否改变？ | 起始/终点组成、独立和混合条件 |
| 图 6 环境依赖后果 | 生态位改变如何影响肿瘤表现？ | 独立生物学重复、时间与交互定义 |

若缺少某环节，应在标题和结论中降低主张，不用示意图将缺失箭头画成实线。

## 9. 预先规定的失败分支

| 观察到的问题 | 应做的处理 | 不应做的事 |
|---|---|---|
| 面板缺关键候选 | 更换可测候选/平台或明确限制 | 把缺失测量写成零表达 |
| 来源状态被非恶性来源混淆 | 重新确认细胞身份与分区 | 直接把 spot 基因归给恶性细胞 |
| 关联由单患者驱动 | 降低泛化结论，单独报告 | 用更多同患者细胞放大显著性 |
| 换合理半径后方向不稳定 | 检查尺度/几何与机制，报告不稳定 | 只保留最小 P 的半径 |
| 材料与状态关系不存在 | 停止声称材料中介，考虑替代路径 | 将 ECM score 填补成材料证据 |
| 干预只改变内在生长 | 重设环境作用假说或拆分两种效应 | 仍将全部终点归因于邻域 |
| 混池无效、独立扰动有效 | 检查补偿和共享环境 | 把混池无效当作基因无功能 |
| 代码缺配置或拟合步骤 | 记录缺口、请求原配置、显式重建替代分析 | 声称已经精确复现 |

## 10. 可交接的数据合同

```text
project/
  inputs_manifest.json         # 来源、版本、许可、访问条件
  definitions/                 # 来源/受体/材料/终点的定义
  cell_tables/                 # image_id + cell_id，坐标单位明确
  roi_tables/                  # 计数、面积、分母、采样和排除
  matrix_assays/               # 实测材料及供体/批次
  perturbation_metadata/       # 身份、目标验证、起始组成
  models/                      # 公式、设计矩阵、诊断、全部比较
  sensitivity/                 # 尺度、阈值、零模型、留一患者
  figures/                     # 每张图可追溯到输入表与脚本
  results_manifest.json        # 实际生成结果；未完成项不伪装存在
  environment.md               # 实际运行版本，不凭记忆填写
```

这不是要求再造一个复杂工作流引擎。现有分析框架只要能保留这些输入、定义和输出，就足以让同行接续工作。

## 11. 可用于开题或组会的完整表述

“我们拟研究稀有恶性细胞状态是否通过局部胞外材料环境组织免疫保护生态位。首先在患者单细胞数据中分离来源比例与条件强度，再在空间数据中检验局部来源暴露与髓系、T 细胞数量及状态的关系；随后用指定材料实测与因子设计区分材料、可溶性背景及其交互；最后以有限原位扰动和混合条件检验跨细胞作用及环境依赖适应度。分析以患者/独立肿瘤为生物学重复，明确处理空间尺度、重叠与组成分母，且把相关、非细胞自主、非线性和中介机制分别验证。”

这段表述是计划，不是研究结果。完成后应按实际证据改写，其中任何未被证实的箭头均应保留不确定性。

## 12. 这一 idea 最终想建立什么？

不是另一个“高低表达＋浸润相关”故事，而是一个更可检验的组织规律：**某些细胞状态的功能重要性可能由局部暴露和材料组织能力决定，而非由它们在整个肿瘤中的比例决定。**能否成立，必须允许数据和干预给出否定答案。
