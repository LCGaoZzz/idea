# 10｜对应“纯起始克隆、早中晚期小鼠 Xenium”的完整研究 idea

[返回](../README.md) · 本章全部方案为 **T：迁移建议／假说**，并非本文已在该小鼠项目中验证的结论。用户已提供背景只有：用很纯的肿瘤克隆型造模，小鼠初期、中期、末期分别取多个样本做Xenium。癌种、每期动物数、时点、panel、取样是否重复和DNA／谱系证据未明确，不作补写。

## 1. 一个能够被反证的主问题

**肿瘤进展中观察到的微环境变化，主要由整体组成与组织几何重构解释，还是在这些变化之外还存在癌细胞／TME状态及其局部组织关系的重排？这种重排与遗传克隆变化是否可被独立区分？**

前半问题可以先用现有空间表达和元数据检验。最后一句涉及遗传身份，没有独立证据时保持未回答，不用表达聚类替代。本文提供分层分析参照，不直接提供这个项目的生物学答案。

## 2. 对应与不对应

| 本文结构 | 可对应的小鼠项目对象 | 不对应的地方 |
|---|---|---|
| 治疗前患者表达背景 | 各动物的癌细胞表达概貌 | 小鼠阶段不是pCR／RD，不继承应答方向 |
| 癌细胞MP与TME细状态 | 跨阶段可比较的状态字典 | 人类marker、程序数目、阈值不能直接搬到鼠panel |
| 患者级状态频率 | 动物级数量／条件比例／评分分布 | 多切片不等于多动物 |
| 个体内局部niche | 每动物的局部组织组成 | 不强行复用30μm或10个niche |
| CNA支持恶性身份 | 需要验证的癌细胞身份或候选CNA | 不等于已建立遗传亚克隆或谱系树 |
| 基线与后续应答关联 | 早中晚群体阶段差异 | 截面阶段序列不等于同细胞纵向追踪 |

## 3. 首先建立三个不互相覆盖的标签

`clone_id`：仅在有遗传／谱系证据时赋值；证据类型、分辨率和不确定性随标签保存。

`state_label`／连续program_scores：来自表达状态，可重叠、可逆或受环境驱动，不默认遗传稳定。

`region_label`：由组织形态、病理、结构或预先规定空间规则定义，记录来源；若用同一状态定义区域，后续状态富集有循环风险。

起始克隆纯度高，减少某些起始混合解释，但不证明随后无遗传分化；表达分化也不证明发生遗传克隆演化。这两个方向都要限制。

## 4. 用现有数据比较四个竞争模型

### M0：组成和几何已经足够解释主要现象

各期肿瘤面积、癌／间质区域比例、总密度、组织边界和坏死发生改变，导致某些细胞对更常邻近。该模型不要求额外的状态间空间偏好。

最小检查：每动物输出有效面积、区域占比、各谱系密度及候选接触机会。先比较这些量能解释多少整体变化，不把组织扩大造成的接触增加直接写为相互作用增强。

### M1：在可比来源和背景中，状态分布仍改变

同一谱系、相近区域中，连续程序分布或谱系内状态组成随阶段变化。此时仅有M0不够，但仍不必假设细胞之间产生新作用。

最小检查：各动物分别保留数量、父谱系分母和评分分布；在预先指定区域中比较阶段；检查检测深度、unknown、可辨marker和注释误差。新cluster只是候选证据，不能直接叫新克隆。

### M2：在组成与背景之外，状态之间有额外组织重排

保持已知组织机会后，某对状态的邻近富集仍随阶段改变，而且跨动物重复。它支持额外空间组织，不识别作用方向。

最小检查：先选少量关系，逐动物进行条件空间检验；比较不同合理尺度和保留自相关的替代零模型；再汇总动物级效应。不用细胞级P值制造独立重复。

### M3：遗传身份与局部生态关系确实不同

只有当克隆定义有独立支持时，才比较同一表达状态在不同遗传克隆周围的空间关系，或同一克隆跨阶段的状态变化。

最小检查：核对克隆证据来源、区段稳定性、panel覆盖、DNA／突变或谱系支持、克隆和状态的定义是否共享用于证明的基因。缺少这些时，M3为不可识别，不是阴性结果，也不以更高Leiden分辨率补上。

四个模型可以同时部分成立。目标是贡献分解和排除替代解释，不是为了得到单一故事而强选一个。

## 5. 采样结构决定可用的统计单位

不同时间点若取自不同牺牲动物，是分阶段横断面序列。可以分析群体状态和组织结构的阶段变化，不能观测同一细胞的路径。若同动物重复取样，应有重复测量模型，并考虑取样位置和取样本身的影响。

数据至少保存 `individual_id → sample_id → section_id → ROI → cell_id`。不能在不确认是否重叠／相邻的切片之间随意汇总密度，也不能把同一细胞重复覆盖的区域当新的组织面积。

若阶段与技术批次完全重合，统计上不能仅靠integration把二者分开。更多细胞不能创造缺失的跨批次对照。先检查设计矩阵秩与交叉分布，再决定哪些结论可估计。

## 6. 不要把所有背景变量都自动“校正掉”

技术批次可能是混杂或不可分离因素；肿瘤大小、坏死和区域比例可能是阶段效应的一部分或中介。调整后回答的是“相同背景下是否还有剩余差异”，不是总体阶段变化。

建议预先定义两个输出：阶段的总体变化，以及在指定结构背景下的条件变化。后者消失可能说明过程通过区域重构实现，而不意味着没有生物学。不得根据哪个版本更显著才选择因果叙述。

## 7. 现有 Xenium 先检查什么？

| 优先级 | 检查 | 得到不同结果时改变什么决策 |
|---|---|---|
| 0 | 动物、阶段、批次、切片、面积、排除流程 | 不可分离时收窄阶段结论；不先解释机制 |
| 1 | panel基因覆盖、来源marker、unknown及分割归属 | 分不清状态时合并或未定，不强行注释 |
| 2 | 数量／密度、父谱系比例、评分分布分开 | 决定先研究招募扩增还是状态变化 |
| 3 | 候选关系的条件空间检验 | 区分组成机会与额外组织偏好 |
| 4 | 留出动物或动物重抽样的稳定性 | 决定关系是否值得独立确认 |
| 5 | 只有遗传证据足够时加入clone维度 | 避免将状态变化包装成克隆演化 |

本项目 `code/audit_inputs.py` 只覆盖ID／标签合同及部分计数分母检查；不自动完成上述生物学判断，也不替代完整空间分析。

## 8. 面板与 CNV 迁移的特别限制

先计算基因沿染色体／区段的覆盖和实际检测，而不是用“5k”字样判断足够。靶向panel不是均匀基因组抽样；转录程序成片、细胞密度和相邻细胞信号都可能形成类似空间pattern。

有匹配全转录组时，可在留出个体中将其限制到目标panel，检查身份／候选CNA模式的稳定性；这评估信息损失，不等于DNA真值验证。没有匹配资料时只能报告覆盖、敏感性和不确定性，不设未经支持的通用“多少基因就能恢复克隆”阈值。

在表达程序和候选CNA使用同一组基因时，可把驱动区段基因移除后重评估程序作为敏感性分支，但这也会删除真实剂量效应，不能把此操作当作纯粹去噪。需要同时保留原分支和明确的估计对象。

## 9. 时间顺序能支持什么，不能支持什么？

早期A多、晚期B多可由A转B、B选择性扩增、A死亡、B迁入或取样区域改变产生。只知道各时点边际分布，通常无法唯一识别转移矩阵，反例见[数学附录](09_MATH_AND_STATISTICS.md)。

可交付的“时空演进模型”应标记三层：直接观察的阶段分布；在明确假设下推断的联系；需实验验证的机制箭头。趋势连续不等于谱系连续。时间信息有价值，但不应因为存在三个阶段就降低对追踪证据的要求。

## 10. 什么结果才值得升级新实验？

优先候选需同时具有可信来源、解释清楚的分母／强度、跨动物方向一致、合理空间零模型下的额外关系，以及明确尚未排除的竞争解释。仍需以效应大小和区间而非单一P值判断投入。

下一实验应专门区分一个有意义的竞争对：例如目标状态影响接收者，还是两者共同响应环境。设计中区分被改变的对象和被测响应的对象，并考虑细胞数变化、组织损伤、处理背景和时间窗口。这里给出设计逻辑，不假定某基因必为靶点，也不提供未经该模型验证的具体操作参数。

若目前仅细胞级显著、动物级不稳，或阶段与批次不可分离，最有价值的是修正统计单位和补齐可比较设计；不是立即追加昂贵平台。若来源清楚但空间偏好消失，可以转向总体区域重构，而不必为保住局部机制故事反复调半径。

## 11. 建议最终可分享的产物

样本纳入与可估计性表；冻结状态与来源证据字典；每动物计数／分母／评分表；区域与候选空间效应表；每个假说的竞争解释和反证记录；克隆证据与未知状态清单；观察—推断—假说分层的时空模型。

这些产物能让未参与项目的人检查逻辑，也让失败结果改变研究计划。它们比只保留聚类图、弦图和最后一张机制示意更接近一个可复查的完整idea。
