# 13｜完整 idea 设计蓝图：把论文故事变成可判定的研究动作

本章是前十二章的贯通练习，不是另一个未经证实的机制故事。**除明确标出的 P／C 陈述，其余均为 I 类数学解释或 T 类迁移设计。** 下面的数值全部为人工构造，不来自论文或任何真实动物。配套 [decision_examples.py](../code/decision_examples.py) 实际检查七个数学例子，回执见 [decision_examples.json](../validation/decision_examples.json)。

## 一、先用一句话限定完整 idea

**核心命题：组织表型的差异可能同时来自信号来源、来源内部状态、细胞组成、空间组织与研究对象选择；先分开这些量，再检验它们之间尚未被解释的关系。**

【P】论文将治疗前癌细胞表达、TME 状态、跨患者共现和组织内空间结构与后续应答关联起来。Fig. 3d、Fig. 3e,f 和 Fig. 5 分别提供来源、测量指标与跨尺度组织的关键例子。原文入口：[正式版](https://www.nature.com/articles/s41586-026-10469-9)。具体结果和取样分母请读第01、02、04、05、06章，不把下列教学数字当作原文结果。

【I】把论文放在 `Xenium-CNV` 下，应提炼的是克隆—状态—组织研究的证据结构，而不是将这篇文章改写成 CNV 克隆追踪研究。至少存在五种不同对象：

| 对象 | 最小定义 | 必须避免的等同 |
|---|---|---|
| 恶性身份 | 细胞属于肿瘤的证据判断 | 表达推断 CNA 阳性不等于完整遗传谱系 |
| 遗传克隆 | 有共同遗传／谱系证据的一组细胞 | 同一表达 cluster 不等于同一克隆 |
| 表达状态 | 细胞在测量时表现的程序 | 表达相似不等于稳定身份或共同祖先 |
| 局部邻域 | 在给定几何定义下观察到的周边组成 | 相邻不等于作用方向或功能依赖 |
| 阶段表型 | 独立个体在不同阶段的分布 | 阶段顺序不等于观测到同一细胞的转变 |

## 二、研究主线不是“分群后找 marker”，而是连续压缩竞争解释

### 2.1 第一关：信号来源

提出问题：整体信号增加，是某来源更多，还是来源内表达更强？最小设计是来源分解；其不可替代性在于混合表达本身通常无法唯一识别来源和强度。身份判定应尽可能独立于候选程序，避免用同一套 marker 同时定义细胞与证明结论。

失败时停止在来源不确定，而不是用更高分辨率聚类掩盖不确定性。通过时也只推进到“谁在表达”，不能跳到“谁在驱动”。

### 2.2 第二关：统计对象

提出问题：状态频率、谱系比例、面积密度和连续评分是否讲了同一个故事？最小设计是对同一候选分别记录这些量。无父谱系细胞与父谱系存在但目标状态为零，是不同事件；前者的内部比例未定义。

失败时应改变表述，例如从“细胞减少”改为“谱系内部比例降低”。通过时仍应排除捕获量、组织取样和标签变化，而不是立即解释为状态转化。

### 2.3 第三关：空间机会

提出问题：候选状态接近，是因为数量多、共同占据某区域，还是存在额外空间组织？最小设计是在明确保留组成和背景的零模型下比较实际与预期。

失败时保留区域共同富集的解释，不等于否定所有生物学。通过时支持额外组织结构，但共同刺激与共同定位到第三种结构仍未排除。

### 2.4 第四关：独立个体与外推

提出问题：结果是否依赖个别动物、特定切片或全数据筛选？最小设计是以患者／动物为独立单位，检查每个个体的方向，并对需要学习的流程按个体留出。

失败时降低外推层级；通过时提高可重复性信心。预测成功仍不使特征成为因果靶点；预测失败也不能证明某过程不存在。

### 2.5 第五关：机制与时间

提出问题：若宣称 A 影响 B 或 A 转化为 B，究竟还缺哪种直接证据？若缺的是方向性，应设计相应干预及替代解释对照；若缺的是谱系，应寻找独立遗传／谱系约束。不要用增加一个算法代替增加可识别信息。

## 三、七个会改变研究判断的可执行例子

### D01：组成与来源内强度可以精确分开，但不是因果分解

在线性尺度令总体信号为 $X=\sum_c w_c\mu_c$。其中 $w_c$ 是贡献权重；对于混合 RNA 信号，通常不应未经证明就当成细胞数量比例。

取两次测量的 $w_0=(0.2,0.8)$、$w_1=(0.4,0.6)$，来源内强度分别为 $\mu_0=(10,1)$、$\mu_1=(12,1)$。总体信号从 2.8 到 5.4，增加 2.6。

使用对称恒等分解：

$$\Delta X=\sum_c\Delta w_c\frac{\mu_{1c}+\mu_{0c}}2+\sum_c\Delta\mu_c\frac{w_{1c}+w_{0c}}2.$$

结果为组成项 2.0，来源内变化项 0.6。**决策意义：总体信号增加不能全部归于来源内程序激活。** 此式适用于所定义的线性量；对 log、z-score 或模块分数，不能未经检查直接解释为物理混合量。

### D02：精确加和并不意味着归因唯一

同一组数也可写成：

$$\Delta X=\sum_c\Delta w_c\mu_{0c}+\sum_cw_{1c}\Delta\mu_c.$$

组成项变成 1.8，来源内变化项变成 0.8，总量仍是 2.6。交互贡献被不同约定分配了。

**决策意义：报告分解约定，不把某项占总变化的百分比当作实验测得的因果贡献。** 对称分解减少基准选择的不对称性，但没有自动解决混杂和反事实识别。

### D03：内部占比减半，目标细胞可能一个也没少

两个同为 2 mm² 的完整观察区域，目标细胞都是 100 个，父谱系分别有 200 与 400 个细胞。目标状态的谱系内比例为 50% 与 25%，但目标密度始终为 50 个/mm²。

**决策意义：若拟研究细胞清除或减少，必须检验密度／数量，而不是只看谱系内部比例。** 若没有可比面积和回收信息，诚实保留“相对组成”的结论。已有父谱系中未检出目标状态也不证明组织中绝对不存在它。

### D04：接触机会增加不要求细胞相互吸引

在无限平面、均匀 Poisson 目标点过程的教学模型中，半径 $r$ 内至少有一个目标的概率为：

$$P(\text{至少一个邻居})=1-\exp(-\lambda\pi r^2).$$

取 $r=0.03$ mm，目标密度从 100 到 400 个/mm²，该概率约从 0.246 增至 0.677，即使没有任何相互吸引。

**决策意义：接触率或最近距离的变化必须与可接近机会比较。** 这里的 30 μm 仅用于教学计算，不能当作新项目推荐半径。真实组织有边界、孔洞、不均匀密度与区域限制，本公式不是可直接用于组织检验的零模型。

### D05：阶段间标签误差不同，足以制造状态比例差异

设真实状态比例始终为 $p=(0.5,0.5)^T$，误分类矩阵每列代表一个真实状态，每行代表输出标签。若两次测量的矩阵为：

$$C_0=\begin{pmatrix}0.9&0.1\\0.1&0.9\end{pmatrix},\qquad C_1=\begin{pmatrix}0.6&0.1\\0.4&0.9\end{pmatrix},$$

则观测比例 $C_0p=(0.5,0.5)^T$，而 $C_1p=(0.35,0.65)^T$。

**决策意义：不能只报告总体注释一致性。** 应按阶段、区域和 QC 检查 marker 可测性、低置信度标签和 unknown。没有独立真值时，无法从同一参考的反复投票反推出真实误分类矩阵；最多进行透明的敏感性分析。

### D06：完全不转变与全部互换，可以产生相同的截面比例

若 $p_0=(0.5,0.5)$，转移矩阵为恒等矩阵时无人转变；为交换矩阵时所有对象换成另一状态。两者都满足 $p_1=p_0T=(0.5,0.5)$。

**决策意义：即使两端比例完全已知，也不能唯一识别细胞转移。** 加上扩增、死亡和迁移后，可能解释更多。不同牺牲时间点的小鼠组织可支持群体阶段演替，不自动支持同一细胞 A→B。纯起始克隆也不能消除后续选择和状态可塑性的不可识别性。

### D07：先判断代码差异是否改变判定，再判断它的重要性

【C】上游固定提交 `fbe1dd3b1db05dd5e9f02485a45fdd438d6af9fb` 中，[copykat_mix.R:160–235](https://github.com/navinlabcode/tnbc-chemo/blob/fbe1dd3b1db05dd5e9f02485a45fdd438d6af9fb/analysis/scripts/copykat_mix.R#L160-L235) 对 CNA score 做参照分位缩放，并将标准化后的 score 阈值限定为至少 1。源代码解读和论文文字差异见第03章。

【I】在有限且非退化的参照下，这个 score 条件等价于原始分数严格超过参照 99.5% 分位。下界从 0.5% 改成 5%，保持上界与阈值截断不变时，二分类可不变。例子的参照为 1 至 100，99.5% 分位为 99.505；查询值恰好等于上界时不通过严格大于条件。

**决策意义：把“文字不同”“数值不同”“实际标签不同”分开。** 本例只验证 score 子门槛，不包含 ACC、完整恶性判定或任何真实细胞。它不能证明所有软件版本、退化输入和作者最终对象均满足同样结论。

## 四、把项目拆成三个竞争模型，而不是提前选择机制故事

以下为 T 类模型设计；不是作者已执行的分析，也不声称能用一个模型穷尽组织演变。

| 模型 | 要解释的变化 | 现有数据最小检查 | 支持后的结论上限 |
|---|---|---|---|
| A：组成／几何模型 | 状态对接近程度随数量和区域面积改变 | 逐动物的密度、父谱系比例、区域面积、边界机会 | 组成和区域重构足以解释多少观测变化 |
| B：来源内状态模型 | 同类细胞中的评分／状态分布发生额外变化 | 同谱系、可比区域的连续评分与内部比例，并审查技术差异 | 来源内状态分布与阶段相关；不是追踪到转化 |
| C：额外空间组织模型 | 同等组成和背景下仍有邻近偏好 | 逐动物的条件空间富集和背景敏感性 | 存在额外组织结构；不是已确定作用方向 |

A、B、C 可以同时成立。比较的目标是识别哪种解释仍有必要，而不是选出唯一标签。对于不同输出变量，先各自建立清楚的估计量；只有预测同一个终点、采用相同留出划分时，才适合将模型预测性能直接比较。

### 4.1 一个可复核的数据合同

不要把所有信息混进单细胞 `obs` 后直接建模。最低保留以下相互关联的表；字段是建议，不是论文原始表结构。

| 表 | 主键与内容 | 关键约束 |
|---|---|---|
| 样本表 | animal_id、sample_id、stage、time、batch、纳入与排除原因、重复取材标记 | 一个样本不能无说明地映射到多个动物；时间定义一致 |
| 区域表 | sample_id、region_id、mask/面积、区域定义、有效边界 | 不跨独立 ROI 连边；区域定义不要直接用待检验表型循环定义 |
| 细胞表 | sample_id + cell_id、坐标、parent_type、state、连续评分、置信度、unknown 原因 | 细胞 ID 可在不同样本重复，但复合主键必须唯一 |
| 状态字典 | state_id、parent_type、marker、程序版本、互斥／多标签属性 | 未覆盖 marker 不等于表达阴性；多标签率不能假装互斥组成 |
| 终点表 | 每个动物／预先指定区域的估计值及其可观察分母 | 记录 NA 原因，不用零替代所有缺失 |

对于临床复现，animal_id 对应 patient_id，并需要治疗路径及结局定义。原研究与小鼠项目不能通过换列名就变成同一个统计问题。

### 4.2 空间零模型必须说明保留与破坏什么

**问题一：状态是否进入某类区域？** 可将区域进入或排斥作为待检验量；不能预先在该区域内条件化后再声称检验了区域进入。

**问题二：在同一类区域中，两个状态是否仍彼此偏好？** 可以在动物、区域、父谱系内随机化状态标签，保留主要谱系位置和各状态数量。若状态有明显斑块自相关，普通标签随机化破坏了斑块结构，应另做分块或背景匹配的敏感性分析；哪种方式合适依赖组织几何。

**问题三：阶段是否改变了这种额外偏好？** 将每个动物的条件富集作为比较对象，而不是将重叠邻域重复计为独立动物。多张切片可以提高个体内估计精度，不自动增加个体间样本量。

预先说明包含不包含中心细胞、unknown 是否进入分母、半径端点、邻居最少数、ROI 边界与空洞处理。不确定的作者规则应标记待补充；新分析的选择应单独记录，不能冒充原方法。

### 4.3 一个值得保留的“停止条件”

若每个阶段只有一个独立动物，无法仅凭大量细胞区分阶段效应与动物特有效应；可以描述这些组织切片，不能把细胞级小 P 值当作群体阶段证据。若批次与阶段完全重合，统计调整也无法凭空创造区分两者的信息。

若缺失动物、提前终止或 QC 排除可能与病程有关，先审查纳入机制。若肿瘤大小或坏死是阶段作用的中介，调整它们改变了研究问题；分别报告总体变化与预先指定条件下的剩余变化，避免“调整后不显著，所以没有生物学”的错误。

## 五、CNA／克隆迁移需要额外的一道可识别性关卡

### 5.1 输入限制不是可通过改名消除的

【I】用全转录组建立的恶性身份逻辑，不能无条件改名为靶向空间 panel 上的精确克隆识别。有限基因的染色体覆盖不均、状态表达、深度和分割误差都可能影响表达型 CNA 代理。本文提供的是研究设计参照，不是对任意 Xenium panel 的 CNV 精度保证。

【T】先制作 panel×染色体区段的覆盖表，检查候选 CNA 是否由少量强状态 marker 主导，审查正常参照的选择与空间可比性。先做可分辨性检查再拟合更多克隆；不能为得到期望数量的克隆而调节阈值。

### 5.2 避免用同一信号同时定义克隆和证明克隆相关程序

若某表达集合决定了 CNA／clone 标签，再用同一表达集合发现“clone 特异程序”，存在同源信息循环使用。最小检查是基因集合重叠与替代标签敏感性；更有力的约束来自独立 DNA／突变／谱系证据。排除重叠基因也不能自动移除整段表达协变或技术关联，因此应如实说明残余依赖。

### 5.3 应明确的四种结论等级

“候选遗传标签与空间位置相关”弱于“独立确认的克隆具有不同局部组织”；后者又弱于“该克隆改变了局部组织”。最后一种需要方向性与作用证据。还应区分“不同克隆占据不同位置”与“同一区域中不同克隆对应不同邻域”，它们对空间机会的条件化不同。

## 六、可以直接写进研究计划的终点与决策句

**主要终点示例：** 在预先定义的组织背景内，候选来源状态与接收状态的动物级额外邻近富集是否随阶段改变。阶段顺序、对比方式、状态字典与空间定义必须先记录。该终点不是本文原终点，也不自动是最适合所有项目的终点。

**结果支持 A：** 差异主要由细胞数量或区域面积解释；优先研究组织扩张和细胞组成，不把剩余证据不足包装成精细通讯机制。

**结果支持 B：** 来源内状态变化稳定，但没有额外空间偏好；可优先研究共同环境或状态调控，不以缺少共定位证明远程通讯。

**结果支持 C：** 额外空间关系跨动物重复，来源和注释可靠；值得考虑围绕方向性和共同上游替代解释设计新实验，仍不宣称机制已成立。

**结果对敏感性高度依赖：** 暂缓机制升级，优先检查分母、区域定义、标签稳定性和样本选择。没有一致结论本身是有效结果，不能通过筛选半径／阈值／细胞子集制造确定性。

## 七、执行、核验与引用

在该 idea 的根目录运行：

```bash
python -m py_compile code/decision_examples.py
python code/decision_examples.py
```

脚本只将 JSON 写到标准输出，不读取患者数据、不修改已有文件、不调用原作者分析。失败会返回非零退出状态。实际回执包含脚本 SHA-256、Python 版本、七项结果以及 patient_analysis_runs=0、animal_analysis_runs=0。

本次新增七项检查在 Python 3.13.5 中实际通过。它们证明的是恒等式或构造反例，不证明真实标签、空间零模型、患者结论或部署性能。原目录的 `toy_results.json` 和 `repository_checks.json` 是前一提交的历史记录；本次没有重新运行原来的二十项测试，也不把两批数字相加宣称获得二十七项独立生物学验证。
