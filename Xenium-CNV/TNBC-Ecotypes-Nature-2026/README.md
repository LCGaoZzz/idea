# TNBC 生态型：从信号来源到空间组织，再到可检验的研究设计

> **定位**：Yan、Lin、Kumar 等，*Ecotypes of triple-negative breast cancer in response to chemotherapy*，Nature 654, 1088–1097 (2026)，DOI [10.1038/s41586-026-10469-9](https://www.nature.com/articles/s41586-026-10469-9)。这是可持续维护的文献研究 idea、方法重建与代码审计项目，不是原论文患者数据的端到端复现报告。
>
> **目录边界**：放在 `Xenium-CNV` 中，是为克隆—状态—生态位研究提供方法论参照。本文的 CNA 主要用于恶性身份识别；癌细胞表达 archetype/metaprogram 不等于 DNA 克隆，空间 niche 不等于谱系。这不是“Xenium 已恢复肿瘤克隆树”的示例。

## 核心问题

当治疗前组织中的一个表达特征与后续应答相关时，它可能来自细胞比例改变、特定细胞内部状态改变、组织区域重构、共同环境，或者取样与分析选择。本文的价值是分开这些对象，再尝试连接它们，而不是用一个整体分数解释所有层级。

本项目沿着“混合信号 → 来源 → 患者表达背景 → 细胞状态 → 跨患者共现 → 组织内邻域 → 预测与外推”重建故事，并在每个箭头旁保留竞争解释、最小检验与结论上限。

## 最值得迁移与最不应照搬

最值得迁移的是：对同一候选关系，分别检查跨个体协变、个体内额外空间组织、独立个体可重复性。最不应照搬的是：先在完整数据上发现／筛选特征，再把下游划分命名为“独立验证”。
