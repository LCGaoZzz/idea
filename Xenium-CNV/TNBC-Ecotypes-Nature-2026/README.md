# TNBC 生态型：从信号来源到空间组织，再到可检验的研究设计

> **论文**：Yan、Lin、Kumar 等，*Ecotypes of triple-negative breast cancer in response to chemotherapy*，Nature 654, 1088–1097 (2026)，DOI [10.1038/s41586-026-10469-9](https://www.nature.com/articles/s41586-026-10469-9)。本目录是完整文献 idea、方法重建与代码审计，不是患者数据的端到端复现报告。
>
> **目录边界**：放在 `Xenium-CNV` 中，是为克隆—状态—生态位研究提供方法论参照。本文的 CNA 主要用于恶性身份识别；表达 archetype/metaprogram 不等于 DNA 克隆，空间 niche 不等于谱系。不能把本文当作“Xenium 已恢复肿瘤克隆树”的实例。

**【I：研究解释】** 基于数据定义、数学关系或设计逻辑的推理；写明假设和反例，不冒充作者已做实验。

**【T：迁移建议／新假说】** 新项目的动作、模型和实验判据；技术复用不等于生物学外推，不宣称未经检索的新颖性。

## 五条启发及其改变的决策

| 原则 | 会改变的研究判断 |
|---|---|
| 先确定来源，再解释意义 | 来源内表达不等于自主产生，决定下一步查来源误判还是上游刺激。 |
| 拆开数量、组成和强度 | 占比下降不等于细胞减少，决定研究招募／扩增还是状态调控。 |
| 分开共现、邻近和功能 | 先问额外空间组织，再讨论作用方向；不以不共定位证明远程通讯。 |
| 检查谁进入了分析 | 处理转轨、提前终止和 QC 排除可能改变目标人群，不能自动填补缺失结局。 |
| 留出整条学习流程 | 特征发现和筛选也是模型的一部分，不能只留出最后一次拟合。 |

第08章逐条展开原则、原文依据、被挑战假设、抽象过程、迁移条件、最小动作、反证与证据状态；第12章提供行动表，第13章把它们连接成可执行设计。

## 最值得迁移与最不应照搬

最值得迁移的是：对同一候选关系分别检查跨个体协变、个体内额外空间组织、独立个体可重复性。最不应照搬的是：全数据发现／筛选特征，再将下游分割命名为独立验证。
