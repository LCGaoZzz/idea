## 3. 数据合同建议

### 样本级

模板见[sample_manifest.tsv](../templates/sample_manifest.tsv)。ID应唯一且稳定；每张切片只能明确归属于某个组织块和生物学对象；时间、z坐标、批次不得混用。未知值保持为空并记录原因，不填0冒充已知。

### 局部观测级

建议字段：`biological_id, section_id, cell_or_spot_id, region_id, clone_label, clone_evidence, cell_type, distance_um, normalized_depth, tissue_area_um2, boundary_censored, annotation_version`。

计数矩阵保留`raw_counts`、归一化表达与模型残差的不同语义；species、genome_build、gene_id_namespace必须明确。空间坐标必须有单位及变换记录。

### 效应级

建议字段：`analysis_id, response, biological_id, eligible_n, excluded_n, estimate, uncertainty, test_family, adjustment_scope, missing_reason, model_version`。比例结果必须说明分子/分母，密度必须说明有效组织面积。

## 4. 最小可执行数学检查

在本目录下运行：

```bash
python scripts/evidence_sanity.py
```

依赖：Python标准库。实际验证环境为Python 3.13.5；脚本使用Python 3.10及以上的类型语法。无随机数，不需要设置随机种子。输入为脚本中的合成例子；输出为测试日志及JSON摘要，失败时返回非零状态码。

检查范围：原文有符号CNV公式的同向、反向、全中性、非法输入；公开硬调用逻辑的简化对称性反例；公开概率路径单窗口与论文定义的差异；固定宽边缘带的几何稀释及边界条件。

代码中`paper_signed_similarity`只处理**已对齐、合法且长度相同的窗口向量**。它不是完整CNV调用器，不负责真实segment拆分、基因坐标转换、克隆归组或参考选择。`simplified_public_hard_score`是单位格网等价例子，`single_window_pred_score`仅处理一个窗口；均不声称是作者R函数的完整翻译。

## 5. 原作者代码如何恢复，而不是“换路径后直接跑”

首先固定[repository_pins.tsv](../evidence/repository_pins.tsv)中的快照，保留只读副本。其次取得真实输入、服务器外部helper、最终参数及输出绑定。环境应记录实际依赖版本，而不是把论文中的历史版本默认为当前可直接安装，或反过来用当前默认替换历史设置。

对具有递归删除行为的边界脚本，先移入隔离workdir，关闭无条件删除，并将实际解析参数写入run manifest。对于CLI类型、坐标单位和可选数据库分支，先做小输入接口测试。任何修改保存patch及原因；修改后的运行证明的是修改后代码行为，不是原代码行为。

### CNV冲突的最小处理顺序

1. 取得作者最终使用的相似度矩阵、分支选择及clone标签表。
2. 在同一输入上分别实现论文定义与实际选中的代码定义；保留原结果，不覆盖。
3. 比较矩阵范围、对称性、对角、聚类和人工修订前后标签。
4. 检查核心生物学结论是否随选择改变，并寻求独立遗传支持。

在这些步骤之前，不应将本目录的反例描述成真实患者克隆已被推翻。

## 6. 统计验收应围绕研究问题

**重复单位**：结果推广到动物/患者时，应说明实际独立对象数量；细胞/spot级P值不替代样本层证据。

**完全混杂**：时期和批次完全重合、身份和环境完全重合时，明确不可分辨，不能靠新增协变量解决。

**稳健性**：比较合理距离、mask版本、保守分割、参考、可测基因集合与区域大小限制；报告关键结论的方向和效应范围，而不只是最显著一版。

**来源**：同类细胞内效应与总体效应并列。组成是混杂、结果还是中介，需在建模前说明。

**空间依赖**：同一局部区域的观测存在相关；重采样或置换应保持与待检验假设相关的结构。没有足够独立动物时，细胞级置换不会增加总体推广证据。

**三维**：配准和插值误差、实际切片证据与模型预测区分开。联系拓扑和谱系结论必须分别验收。

以上均为建议的验收原则，不冒充本次已运行的统计检验。
