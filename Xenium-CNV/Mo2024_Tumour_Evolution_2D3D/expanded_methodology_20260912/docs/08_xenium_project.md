# 08｜对应分时期 Xenium 项目：先建立可竞争的解释，再建立演进故事

[目录](../README.md)｜[上一章](07_insights.md)｜[下一章](09_code_audit.md)

## 1. 已知背景与未知条件

**已提供背景**：使用较纯的肿瘤克隆造模小鼠，初期、中期、末期各有多份 Xenium 样本。

**尚未确认**：每期独立动物数；是否不同时间牺牲不同动物或同体重复取样；具体肿瘤与接种情境；面板和批次；是否有配对遗传数据、谱系标签、连续切片或同一区域的其他测量。以下不把这些条件当作已具备。

本章全部为【H：迁移建议／待检验假说】，不表示已经分析了该项目数据，也不预设任何细胞类型或基因轴为机制主角。

## 2. 与本文哪里对应，哪里不对应？

| 维度 | 可借用的研究结构 | 不能直接照搬之处 |
|---|---|---|
| 起始遗传背景 | 将身份、状态与环境分开 | 共同起始克隆不证明终点遗传完全相同 |
| 时间信息 | 增加群体阶段比较 | 早中晚不是同一细胞的连续谱系 |
| 空间单位 | 区域、界面、局部环境各自定义 | 小鼠模型的形态不能无条件套人类微区域规则 |
| Xenium测量 | 可直接分析细胞与转录本位置 | 面板数据不是全转录组Visium；去卷积链不是必需 |
| CNV证据 | 独立遗传锚点支持身份 | 151基因窗口、参考和阈值不得照搬 |
| 三维 | 有连续切片时检查连接稳定性 | 不同时间的不同肿瘤不能拼成一个真实三维体积 |
| 外推 | 以独立动物检验结果一致性 | 细胞多、切片多不增加动物重复数 |

【P背景】原文主体为人类组织和连续切片，不是本项目的分期造模设计；Xenium也不是其全部遗传证据来源。〔P：Fig. 1–5；Methods，见来源索引〕

## 3. 第一优先级：确认时期效应是否可识别

建立 `mouse_id, tumour_id, timepoint, section_id, block_id, batch, panel, run_id, tissue_area, z_um` 对照表。未知值保留缺失；z仅在真实连续切片时填写。

如果时期与批次完全重合，模型无法单靠观测把二者区分。将时期当批次校正也可能删除真实变化。先报告交叉覆盖，而不是承诺某个整合算法可以恢复缺失对照。

如果同体重复取样，需考虑重复测量和取样干预；如果不同动物分期牺牲，使用独立时间群体设计。分析单位和因果语言随之改变。

## 4. 建立三套竞争解释

**模型A：总体组成改变。** 不同时期某类细胞更多或更少，但其局部分布与同类细胞状态不必改变。

**模型B：几何机会改变。** 区域大小、边界/面积比及局部可达组织改变，足以解释整体比例或接触数变化。

**模型C：位置依赖的状态／组织关系改变。** 在相似类型和可比较几何条件下，表达状态、分布梯度或局部接触关系仍随时期改变。

这三者可以同时存在。应分别报告时期相关总变化与几何条件下的差异，不把大小一律当混杂，也不把条件化后减弱解读为原总效应不存在。

## 5. 先用已有数据完成的工作包

### 工作包A：测量与分割审计

检查每期有效组织面积、每细胞转录本数、细胞面积、未知细胞、负控/背景及分割边缘比例；比较面板与共同可检测基因。不要通过事后阈值把某一时期更大的真实细胞或低表达状态系统性删除。

对核心候选使用保守归属再分析，观察状态是否依赖边界转录本。该检查可以先于全部亚群精细注释，因为来源不稳定会传递到所有下游程序。

输出：逐样本质量表、纳入/排除日志、共同可测集合、候选指标检验资格表。

### 工作包B：独立定义恶性身份、状态与区域

用已有模型背景、组织形态与合适的独立标记支持恶性身份；表达状态先在共同特征空间比较。不要早中晚各自聚类后，仅凭名称相似强行认为是相同状态。

存在遗传资料时再定义克隆及不确定性；没有终点遗传依据时称“状态/区域”。把用于分组的基因与后续验证指标分开，以免同义反复。

输出：细胞身份依据、状态、区域和遗传证据分列的对象；不确定标签不强制抹平。

### 工作包C：把整体组成和界面结构同时保存

每个动物计算整体比例、组织面积归一化密度、区域面积/周长、可信边界、固定物理带宽密度和界面覆盖。弥散结构不强行设置单一中心。

同时报告绝对距离和相对深度，检查不同合理带宽。边界带相互重叠时要定义唯一归属或报告重叠；否则同一细胞可能被重复计入多个区域。

输出：动物级组成表、区域几何表、距离带/界面片段表，保留每个指标的分母。

### 工作包D：时期×位置，而不只是时期均值

对每个动物估计目标类型的密度曲线和类型内状态曲线，然后比较不同时间群体。问“梯度或边界附近的位置关系是否变化”，而不仅是全局平均是否显著。

变量较多、动物较少时，优先简洁的预定义区域对比和个体效应；不要用数十万细胞支持一个实际上只有几只动物的高度灵活模型。距离带是动物内部观测，不是新的独立重复。

输出：个体曲线、主要效应及不确定性；标明哪些时期与几何条件有共同支持，哪些是外推。

### 工作包E：来源分解与候选优先级

对少量候选同时比较区域总表达、同类型内表达和该类型密度。若区域效应在类型内消失，优先组成解释；若保守分割后消失，优先来源不稳解释；若均稳定，再讨论状态变化。

通信分析只围绕有覆盖、可定位来源、具有空间接触机会并跨动物稳定的候选展开。不要因为某通路在原文重要，就强迫本项目找到同一路径。

输出：每个候选的一页证据卡，包含效应、来源、几何、跨个体稳定性、替代解释和未测变量。

### 工作包F：留出与敏感性

固定主要假说、指标和分区后，留出完整动物评估；数据不足时明确仅有探索性证据。对参考、分割、区域阈值、带宽和可测性处理设置合理敏感性分支，不只汇报最显著组合。

若只有留出同一动物细胞可用，不能称独立动物验证。预测成功也不意味着时间因果或细胞谱系已识别。

输出：主要分析与探索分支分开、结果稳定性矩阵、失败条件记录。

## 6. 可以检验但不应预设成立的假说

**H1：局部组织变化可能先于总体比例的明显变化。** 需要分别估计每期的界面和整体指标，并考虑指标检测功效不同。“一个先显著、另一个后显著”不足以证明先后，应比较效应及区间。三期群体数据最多支持粗粒度的时间关联，不足以恢复任意连续动力学。

**H2：局部环境对状态的预测信息可能超过总体组成。** 比较整体组成模型与加入界面指标的模型，使用留出动物评价。若环境指标就是由目标状态基因构造，需重新设计，否则额外预测可能是信息重复。

**H3：免疫相关改变可能更多表现为位置而非总量。** 只有数据实际支持相应细胞和分布时才保留。不能预设一定有连续间质屏障、稀有亚群或特定非细胞自主机制。

这些是假说，不是跨疾病已成立的定律；阴性或不可识别结果也能改变后续实验选择。

## 7. 哪些结果不值得立即升级为新实验？

候选仅来自一个动物、一张代表图、一个任意带宽、一个分割版本或无法测量完整通路的面板时，先补分析边界。若时期与批次完全重合，优先解决设计识别问题。若核心信号在来源校验后消失，不应继续围绕原来的细胞内机制追加实验。

程序评分显著不等于某单基因是驱动；通信评分高不等于真正作用。先明确实验到底要区分哪两个解释。

## 8. 什么结果才值得升级？

当候选跨独立动物方向较一致，效应不是几何机会、分割和可测性处理的简单产物，且能明确“可能发出作用的对象、出现响应的对象、预期响应与时间背景”时，新实验才更聚焦。

若要区分**状态转换与既存状态扩增**，新增证据应能辨别来源和去向，而非再增加一种状态排序算法。若要区分**共同环境与细胞间作用**，应在保留关键情境的情况下改变候选来源或响应环节，并检验预先指定响应，同时排除一般损伤或组成变化。

必要性、充分性和中介作用需要各自匹配的设计；一次阳性共培养、标记变化或相关性不能同时证明三者。这里仅给研究设计层面的判断，不补写作者未报告的实验条件或运行参数。

## 9. 一条不超出数据的最终叙事

可以组织为：共同起点背景 → 群体时期差异 → 几何与组成分解 → 位置依赖状态改变 → 独立样本确认 → 待检验机制模型。

每一条最终图上的箭头分别标为实测关联、群体时间顺序、模型对应或已干预验证。不要把三维连接、伪时间和跨期最优传输混画成已经追踪的细胞谱系。

这套顺序的价值是让阴性分析也能改变故事：若只支持组成和几何，就写组织结构重组；若还支持类型内状态，再讨论情境相关响应；只有增加相应证据后，才升级为具体驱动机制。
