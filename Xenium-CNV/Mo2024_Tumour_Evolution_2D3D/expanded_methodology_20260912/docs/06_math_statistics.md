# 06｜数学、统计与识别条件：哪些漂亮结果可能回答了另一个问题？

[目录](../README.md)｜[上一章](05_3d.md)｜[下一章](07_insights.md)

本章以【I】原创代数、反例和统计分析为主。作者事实使用【P】，实际代码使用【C】，新增检查建议使用【H】。只有 [run_checks.py](../code/run_checks.py) 中对应的 24 项确定性合成检查已执行；其余模型、敏感性分析和真实数据稳健性检验均未执行。

## 1. 先规定估计目标：细胞平均与动物平均不是同一个数

【I】若动物 j 有 n_j 个观测，组内平均为 ȳ_j，则：

$$\bar y_{cell}=\frac{\sum_jn_j\bar y_j}{\sum_jn_j},\qquad
\bar y_{animal}=\frac1J\sum_j\bar y_j.$$

前者让采到更多细胞的动物权重更大，后者让每个动物权重相同。二者都有可能是合理描述，但不能不加说明地互换。获得更多切片通常提高一个动物内部的估计精度，不会自动提高它作为独立动物的数量。

【H】先明确结论要推广到细胞、局部区域还是动物群体；以独立动物为主报告个体效应和区间，再将细胞级分布作为组织内部描述。动物数很少时，复杂随机效应模型也不能凭空提供稳定的群体方差估计。

## 2. 空间相关性怎样制造过度精确？

【I：示意模型】设 J 个独立动物，每个 m 个观测，同动物内任意两观测相关系数为 ρ、边际方差 σ²，则总体平均的方差为：

$$\operatorname{Var}(\bar y)=\frac{\sigma^2}{Jm}\{1+(m-1)\rho\}.$$

这只是等相关结构下的推导，不是本文数据的实际有效样本量。它说明当动物内相关为正时，增加细胞不再按独立观测的速度降低不确定性。真实空间相关依赖距离、结构和细胞类型，不能用一个固定设计效应修正所有分析。

【H】重采样和置换的单位应匹配假设。检验时期效应时不能任意打乱细胞的动物身份；检验邻接效应时也不能在组织外空白矩形中均匀重放细胞。空间零模型应尽可能保留可达组织、局部密度和所需层级。具体零模型要由备择解释决定，而不是选择最容易拒绝的随机图。

## 3. 混合表达的可识别性

【I】混合信号可表示为：

$$X_{ig}\approx\sum_cw_{ic}\mu_{icg}+\varepsilon_{ig}.$$

w 是各类型对 RNA 信号的贡献，未必是细胞数量比例。只有 X 而没有约束，组成 w 和状态 μ 通常不可唯一分解。单核参考、已知标记和形态可以增加约束，但参考状态变化仍会影响推断。

【P/I】本文参考辅助分配公式在分母正值时满足 Σ_c x̂_gcs=x_gs。守恒证明只需将归一化权重求和等于1；它证明数值总量被分配完整，不证明细胞来源正确。Methods 的总量20示例存在一处文字算术不一致，见第四章。

【H】至少并列检查区域总信号、类型内信号和类型密度。分母为零、参考缺失和未知类别均应保留状态，不用强制归属生成确定结论。

## 4. 界面几何：一个不需要免疫行为改变的反例

【I】圆形肿瘤半径 R，某细胞群仅分布在内侧宽 d 的边缘带，带内密度不变且 0≤d≤R。边缘带占面积：

$$f=\frac{\pi R^2-\pi(R-d)^2}{\pi R^2}=2\frac dR-\left(\frac dR\right)^2.$$

R=100、d=10时 f=0.19；R=200而 d不变时 f=0.0975。若其他组成与检测条件保持相应稳定，整体比例可以下降，而局部细胞组织过程不变。此处是解析几何反例，不是用圆形模型拟合作者肿瘤。

二维边界带面积在局部光滑、带宽较小时近似 Ld；因此 N/(Ld) 与 N/L 分别代表不同尺度的密度。边界曲率、孔洞、重叠带与切片截断明显时，应直接计算实际可分析带面积，而非套近似。

【H】报告整体比例、固定物理距离带密度、边界长度/面积比和距离曲线；检查不同合理带宽。绝对距离与归一化深度不能互相替代。

## 5. 六角晶格面积不是捕获圆面积

【P】本文用每个 spot 对应约8660 μm²的晶格面积估计区域规模。〔P：Methods “Average spot area and microregion size calculation”〕

【I】最近邻中心距为100 μm的规则六角晶格，每点 Voronoi 单元面积为 √3×100²/2≈8660.25 μm²；这不是直径55 μm捕获圆的面积。前者用于近似所代表的组织面积，后者描述实际捕获区几何。两种分母回答不同问题。

【H】迁移到非规则细胞坐标、不同 bin 大小或不同分辨率，不应直接继承8660。应使用实际组织面积、分割面积或明确定义的网格覆盖面积。

## 6. 偏相关系数不是回归斜率

【I】给定深度 x、表达 y 和协变量矩阵 Z（含截距），令 r_x=(I−P_Z)x、r_y=(I−P_Z)y，则：

$$r_{xy\cdot Z}=\frac{r_x^Tr_y}{\|r_x\|\|r_y\|},\qquad
\hat\beta_x=\frac{r_x^Tr_y}{r_x^Tr_x}.$$

前者无量纲；后者随表达单位改变。把 y 乘10，偏相关不变，斜率乘10。对应合成检查已执行，但这不是对作者表中 rho 字段的最终语义确认。

【P/C】Methods 使用偏相关与线性表达式描述深度分析；已读 C07 主要读取结果 TSV。应恢复上游实现和标准化，不能只看变量名就判断 rho。

### 深度归一化也不等于区域等权

【I】把每个区域的深度放到[0,1]不会使大区域自动与小区域等权。普通最小二乘仍最小化 Σ_rΣ_i(y_ri−ŷ_ri)²；更多观测的区域仍有更多项。区域等权可通过区域级摘要或明确权重实现，但二者改变估计目标。

同一区域内，layer/max 与 (layer−1)/(max−1) 呈正仿射关系；当混合不同 max 的区域时，不存在一个适用于所有区域的共同仿射转换。因此不能在合并检验中断言两种编码完全等价。

## 7. 有符号 CNV 相似度的性质

【P/I】第三章的 S 在有效并集上是 −1/0/+1 乘积的长度加权均值，故 −1≤S≤1；交换 A、B 不变；相同且至少有异常时 S=1；相反异常可为−1；全中性则无有效分母。

【C/I】限制在已经对齐的小区间上，C06 无概率辅助函数的分母不对称，产生 S(A,B)=1、S(B,A)=0.5 的反例。此反例只复核公式逻辑，不涉及 R/GenomicRanges 的实际执行。概率分支又是另外一个非负定义；不能混用三者的名称。

### as.dist 为什么值得单独检查

【I/接口事实】R `as.dist` 使用矩阵下三角，不会自动验证并修复不对称性。若输入不对称而未检查，改变样本顺序可能改变采用的方向。当前官方文档用于说明接口语义，不作为论文 R 版本证据。

【H】先验证矩阵而非直接聚类；如发现不对称，查定义与区间处理，不先取均值掩盖来源。对称化也是一个新的统计定义，必须另行说明。

## 8. D=1−S 不总是欧氏距离：一个已执行的反例

【I】四个 CNV 向量均含有效异常，两个窗口等长：

```
A=(-1,-1)   B=(-1,0)   C=(-1,+1)   D=(+1,0)
```

按论文有符号公式得到：

```
S = [[ 1,   .5,   0,  -.5],
     [ .5,   1,  .5,  -1 ],
     [ 0,   .5,   1,  -.5],
     [-.5,  -1, -.5,   1 ]]
```

取距离 D₀=1−S，H=I−11ᵀ/4，构建 B₀=−(1/2)H(D₀∘D₀)H。如果 D₀ 是欧氏距离矩阵，则该双中心 Gram 矩阵应半正定。本例特征值约为：

```
-0.2247448714, 0, 0.5, 2.2247448714
```

存在非数值舍入级别的负特征值，故这种 D₀ **不是一般保证欧氏的构造**。对应合成测试已执行。

【P】论文采用 ward.D2；官方 R 文档说明其内部平方输入差异以实现相应 Ward 准则。

【I】算法能够返回一棵树，不代表在任意差异定义下都能解释为某个原始欧氏特征空间的最小组内平方和。这不证明作者具体矩阵一定非欧氏，也不证明其克隆结果错误。应取得真实矩阵后再检查，并比较适当 linkage 的稳健性。

【H】不要机械将 D 改为√D：只有其数学前提和目标明确时该变换才有依据。最终克隆解释仍需要独立遗传证据，而非只优化聚类树。

## 9. 交叉熵的输入语义：softmax 两次并不等价

【C】Mushroom C18 的 `quantize` 生成概率 p；`forward` 将 p 交给 `F.cross_entropy`。官方接口把第一参数解释为未归一化 logits。

【I】标准类别负对数似然为 L₁=−log(p_y)。源码这条路径等价于 L₂=logΣ_k exp(p_k)−p_y。p=(0.9,0.1)、y=0 时：

```
L1 = 0.10536051565782628
L2 = 0.3711006659477777
```

如果 K 类的 p 趋于目标类 one-hot，则 L₂ 的下确界为 log(e+K−1)−1，而不是0。这说明标度、概率解释和梯度并不相同，但非零损失下界本身不说明训练失败。邻域损失与重建损失的相对作用也可能变化，幅度需真实训练才能量化。

【H】复现原路径与修正语义后的路径分别保留；比较实际梯度、训练曲线、独立重建和留出切片指标。代码改动属于新审计分支，不能与原样复现混记。

本档案只用 NumPy 稳定 log-sum-exp 验证数学差异，没有调用 PyTorch 或执行作者模型。

## 10. 图的回路、空洞与谱系不是一回事

【I】有限无向图包含 V 个节点、E 条边、C 个连通分量，其循环秩为：

$$\beta_1=E-V+C.$$

单个连通 volume 才简化为 E−V+1。树的秩为0，三角图为1；三角图再加一个孤立节点，C变为2，循环秩仍为1。合成代码对重复边、自环和非法节点显式拒绝，因为输入合同限定为简单图。

【P/I】论文区域图的回路描述切片连接拓扑。它不等于组织网格三维孔洞的任意拓扑量，更不等于细胞谱系树发生过的历史。图构造规则变了，E、V、C的解释也会变化。

## 11. 缺失、检验资格和零

【I】三个样本某效应仅一个可估计为1，另两个未测量；把它们当1、0、0后得到1/3，不能称真实群体平均效应。小区域因无核心被排除，同样改变了结论适用总体。

【H】至少保留：面板未测、测到但不能可靠检验、已检验但证据不足、已有方向性证据。要支持近似无效应，还需预定义有意义的效应界限与足够窄的不确定性区间，不能由 P>0.05 代替。

“阳性数/可检验数”只是可检验子集的检出频率。若可检验性与时期、大小或状态相关，不能直接将它外推为总体发生率。

## 12. 可执行的新模型，应先说明不是作者原模型

【H】计数可考虑面积作 offset 的过度离散模型，例如：

$$\log E[N_{jrb}]=\log A_{jrb}+\alpha+\beta_{T_j}+f(d_b)+g_{T_j}(d_b)+u_j.$$

这里 j为动物，r为区域，b为距离带；A必须是有效组织面积，f和g表示位置与时期交互。该式只是待选择的建模结构，不是本文报告的最终方法。应检查样本量、过度离散、零结构和独立重复；不能根据变量名直接选定负二项分布。

比例需保留分子与分母，可考虑适当的二项/过度离散结构；连续分数需检查标度与分布。以每动物的曲线/效应为摘要并作区间估计，往往比用大量细胞拟合过于灵活的模型更可审查。

## 13. 阈值搜索、多重检验与外推

【H】边界宽度、邻域大小、CNV参考、聚类切分和基因集均会改变发现空间。预先指定主要分析，完整报告敏感性网格，不只保留显著设置。多重检验家族应明确是每切片、每病例还是全研究；BH校正并不自动解决样本依赖或事后模型选择。

如果状态定义、分区和验证指标共享同一组基因，应留出目标特征或独立样本。随机拆分同张切片的近邻细胞可能泄漏空间结构；留出完整动物是不同层级的检验。所有预测成功仍不自动识别因果或谱系。
