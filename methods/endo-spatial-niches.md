# 从 CAF 邻域组成到 Endo 多视角空间生态位

更新：2026-09-16。本文是方法参考与研究设计说明，供研究者或科学智能体阅读；具体项目的用户要求优先。原论文方法、数学解释和待验证的 Endo 扩展在下文分别标明。本文未执行 Endo 数据分析，未证明某种扩展优于组成基线。

## 1. 原论文提供了什么思路？

Liu et al., *Conserved spatial subtypes and cellular neighborhoods of cancer-associated fibroblasts revealed by single-cell spatial multi-omics*, **Cancer Cell** (2025), DOI: [10.1016/j.ccell.2025.03.004](https://doi.org/10.1016/j.ccell.2025.03.004)。主要依据为 [STAR Methods：Identification of spatial CAF subtypes](https://pmc.ncbi.nlm.nih.gov/articles/PMC12074878/)；本仓库还保存了用户提供的[方法重建与参数审计](../2026-09-caf-spatial-multiomics-kb/reconstruction/methods/01_mathematical_reconstruction.md)。

**原文报告**：以 CAF 为中心，在同切片内取半径 80 μm 的邻域，计算各类细胞比例；对 CAF × 细胞类型矩阵做 NMF（R 包 NMF v0.27，5 因子），再对 CAF × 因子表示做 Leiden 聚类（Seurat v4.3，resolution=0.1）。按主导邻域组成注释为肿瘤相邻、间质、髓系丰富、淋巴丰富四类空间 CAF。CosMx、MERSCOPE、Xenium 按样本独立拟合。亚型邻域组成除以全切片背景组成，所得富集用于跨样本比较和 Pearson 相似性分析。[原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12074878/)

### 1.1 数学解释：每个中心细胞拥有一个邻域向量

下面的记号解释上述方法，不代表恢复了作者代码。令 $x_i$ 为物理坐标，$z_j$ 为细胞类型，$s_i$ 为切片：

$$
N_i(r)=\{j:s_j=s_i,\ \|x_j-x_i\|_2\le r\},\qquad
n_{ic}=\sum_{j\in N_i(r)}\mathbf{1}(z_j=c),\qquad
q_{ic}=\frac{n_{ic}}{\sum_d n_{id}}.
$$

公式的邻居集合只是一般写法。中心自身是否纳入、边界等号、未知标签是否纳入分母、空邻域如何表示，需作为明确的实现约定保存；当前审计未恢复这些作者实现细节。不能用默认代码悄悄补齐后宣称精确复现。

将所有中心的 $q_i$ 堆叠为 $Q\in\mathbb{R}_{\ge0}^{n_{\rm center}\times C}$，分解为：

$$
Q\approx WH,\qquad
W\in\mathbb{R}_{\ge0}^{n_{\rm center}\times K},\quad
H\in\mathbb{R}_{\ge0}^{K\times C}.
$$

$H$ 表示组成模式，$W$ 表示每个中心的模式权重。Leiden 使用由 $W$ 表示的邻域相似性；原文的五个因子是描述维数，最终空间类别由聚类及组成注释产生。当前尚未恢复 NMF 损失、初始化、随机种子、尺度处理、构图参数及完整类别映射。[已核实参数与未核实项](../2026-09-caf-spatial-multiomics-kb/reconstruction/methods/author_parameters.json)

需要保留的区别：

- 80 μm 是半径；“约 100 个邻居”是数量描述，不是固定 kNN。
- 四类空间语义不等于四个 NMF 因子；新样本不必包含全部四类。
- 背景富集用于类别比较；当前证据不支持将其未经说明地前移为 NMF 输入。
- 独立拟合的因子编号、尺度和簇编号没有天然的跨样本对应关系。
- 中心细胞邻域可以重叠。结果首先给中心细胞赋予空间环境标签，不自动形成覆盖所有细胞、互不相交的组织分区。

## 2. Endo 迁移的数据约定

**以下为新研究的设计约定，不是原论文已经验证的 Endo 分析。**

| 对象 | 约定与作用 |
| --- | --- |
| 大类标签 | 使用 `obs['type1']` 作为邻域大类统计口径 |
| 中心集合 | `type1 == 'Endothelial'` |
| 邻居集合 | 同切片内全部合格细胞，包括非内皮谱系；不能先仅保留 Endo 再计算组成 |
| 精细标签 | `type2` 可辅助精细谱系分析、解释与敏感性检验，不替代主分析的 `type1` 口径 |
| 空间位置 | `obsm['spatial']`；核实单位、拼接方式及与细胞 ID 的对应 |
| 分层元数据 | 核实 `sample_id` 与动物、切片、FOV、批次的对应；使用经核实的切片及坐标系标识限制邻居查询 |
| 分子数据 | 保留原始计数与面板信息；估计分子状态时处理检测深度、稀疏性和覆盖差异 |
| 已有生态型 | `SE`、`InitSE` 的生成过程应审计；它们不是天然独立的真值 |

若 Endothelial 大类含淋巴管内皮，应评估谱系差异与空间环境差异分别贡献了什么。已有 T/NK 标签若来自空间投票，其空间平滑可能被再次用来“发现”空间模式；应利用注释来源与置信度做敏感性分析。若 CD4 身份缺乏独立标记支持，不能用标签名称代替分子证据。

原始对象保持可追溯；新特征、模型、标签和结果保存为独立产物。本文不包含任何特定项目的未公开样本信息。

## 3. 可以探索哪些特征？

以下是待比较的特征视角，保留与否由可测性、误差和验证结果决定，不是必须全部拼接的清单。

| 视角 | 需要量化的对象 | 主要识别问题 |
| --- | --- | --- |
| 邻域组成 | 各 `type1` 类型的比例、计数及有效面积下的密度 | 比例、绝对数量、密度回答不同问题；组织边缘改变有效观察范围 |
| Endo 自身状态 | 中心内皮的基因表达程序或可信分子状态 | 区分谱系、检测深度与状态；评估单细胞稀疏性及聚合引入的平滑 |
| 邻居分子状态 | T、肿瘤、巨噬及其他髓系等谱系内部的状态分布 | 区分“某类细胞更多”和“该类细胞状态改变”；稀有谱系的缺失不是低活性 |
| 组织结构 | 密度、方向性、邻接、界面距离等可定义量 | 坐标推导的几何量不自动等同血管管腔、灌注、屏障或病理结构实测 |
| 功能轴 | 有来源、面板可覆盖的程序、配体–受体或发送/响应特征 | 基因集方向、物种对应及测量覆盖需明确；表达兼容性不等于真实信号传递 |

### 3.1 将丰度和谱系内状态分开

若 $\tilde x_{jg}$ 是经明确变换或模型估计的表达量，一个邻居状态特征的**示意形式**是：

$$
m_{icg}=\frac{\sum_{j\in N_i}w_{ij}\,\mathbf{1}(z_j=c)\,\tilde x_{jg}}
{\sum_{j\in N_i}w_{ij}\,\mathbf{1}(z_j=c)}.
$$

这表示“给定邻居属于类型 $c$ 时，其分子状态如何”，可与该类型比例 $q_{ic}$ 分开研究。权重、变换及统计量都属于候选设计；上述均值不是指定算法。分母为零时，应记录该谱系不可估计，不能填零后解释为分子程序关闭。

对每个分子或轴特征，保存基因/程序来源、物种映射、面板交集、计分方向、分母、有效细胞数和不确定性。未测基因与测得零计数分别记录。单个配体或受体的表达不能独立证明整条功能轴已激活。

## 4. 多视角如何一起使用？

组成基线用于回答“新增信息究竟改善了什么”。组成、内皮状态、邻居状态、结构和功能轴可作为不同视角进入候选表示学习方案；直接拼接、共享或分离潜变量等均需由比较决定，不在本文指定唯一模型。

数学上至少需要审查：

1. **取值与分布**：比例受到总和约束；计数有深度差异；有符号的标准化值不能直接送入要求非负的模型。零、缺失和不可测不能混为同一种值。
2. **尺度与维数**：一个视角拥有更多基因，不意味着应拥有更大的距离或损失贡献。归一化、变换、视角权重和缺失处理都要可追溯。
3. **统计依赖**：邻域重叠、同谱系相关程序、共线性和技术批次可能制造重复信息；消融检验应识别每个视角真正提供的增益。
4. **学习与迁移**：用于宣称泛化的归一化参数、特征筛选、表示和类别映射应在探索/训练数据中学习，再固定后用于验证。独立样本的因子或簇编号不能直接合并。
5. **结果形态**：数据可能支持离散亚型、连续梯度、混合成员或暂不可分型；不能以强制产生更多类别作为成功标准。

## 5. 什么证据能支持可信解释？

这部分是研究评价原则，不表示这些检查已经完成。

| 研究主张 | 需要的证据与限制 |
| --- | --- |
| 多视角优于组成基线 | 统一评估下的增益、各视角消融及计算成本；不能只比较训练内聚类分数 |
| 结果稳健 | 空间尺度、注释、分割、深度、边缘及建模选择的敏感性；允许报告不稳定类别 |
| 捕获了组织关系 | 根据具体零假设设计保留相关组织结构的对照；简单打乱全部细胞未必是有效对照 |
| 能跨样本迁移 | 未用于选模的样本或独立证据；明确类别对齐和未知类别处理 |
| 存在组间生物差异 | 核实动物—切片—批次对应，处理空间相关与邻域重叠，报告效应量、不确定性和多重检验 |
| 具有功能或机制意义 | 区分观测、程序评分、通信预测与因果；独立测量或干预支持的结论强度另行说明 |

细胞数不能替代独立动物数；空间块留出可检查局部泛化，但同一动物的留出区域不能冒充独立动物验证。若缺乏足够生物重复，仍可研究方法稳定性与描述性结构，组间推断需保持探索性。

`SE`、`InitSE`、空间推断的 T/NK 标签及已用于建模的基因/程序可以作为参照或描述，但不能同时被包装成独立验证。保留不参与自适应选模的验证证据；一旦用它反馈修改方法，就应记录其独立性已经消耗。对用于定义类别的同一特征做类别间差异检验，不能单独证明发现了新的生物学类别。

## 6. 如何组织成可回退的研究循环？

Campaign 的候选可以改变特征定义、空间尺度、变换、整合、输出形式和解释。每轮先明确：这个检验能区分哪些竞争解释？什么结果会削弱当前解释？下一轮可以返回任意环节，包括修订问题本身。

评价同时考虑稳定性、可迁移性、独立生物学支持、解释边界和资源成本。评价约定的变更要版本化，必要时按新约定重新比较旧候选，不能将不同口径的分数直接排成同一进步曲线。没有统一“最佳”时，可交付有明确取舍的候选集合。

战役记录应关联实际输入、候选因素、代码版本、配置、随机性、成功、失败和无法判断的结果。提案与评估分工，尽量减少预期结论对评估的影响；语言模型偏好不能替代实际证据。停止原因应区分预算耗尽、当前空间的平台期和证据不足。

## 7. 建议交付的可追溯结果

- 中心与邻居定义、细胞 ID 映射、比例/密度、有效观察范围及缺失标记。
- 各视角的数学定义、来源、变换、尺度、覆盖和有效样本量。
- 学习到的表示、模型配置、类别或连续状态及空间映射；分型置信度和不确定性。
- 组成基线、候选比较、消融、敏感性、零模型与独立验证证据。
- 可复现代码与新结果对象、研究账本、失败记录、适用范围和停止原因。
