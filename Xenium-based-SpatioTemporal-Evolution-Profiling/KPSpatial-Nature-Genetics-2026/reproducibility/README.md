## 1. 这次提交是什么，不是什么

这是依据前次 `reconstruct-bioinfo-protocol` 精读审计包和随后研究启发讨论整理的**完整idea文档树**。沿用事实、代码、解释、建议分层和分析追踪原则；本次没有启动原论文科学重建，不把文档整合宣称为原工作流全链路复现。

此前包的原验证器结果属于此前那个包，不能自动继承给本目录。本目录实际提供并运行的是标准库离线检查，记录在 [receipt](../validation/receipt.json)。科学执行记录为空；`traceability.tsv`没有任何“已执行验证”的论文分析项目。

## 2. 两种执行必须分开

**本目录已执行：**人工最小数据的合同和Python逻辑检查；字节校验后的公共阵列元数据计数。它们不调用Cassiopeia、不读h5ad、不做DE/LR，不访问用户Xenium数据。

**未执行：**原始read处理、谱系矩阵构造、真实树重建、fitness或plasticity重算、邻域DE和LR、转移匹配、qPCR统计重算、原版／修复版对照，以及全部论文图重现。

最小反例支持“某集合差为空”或“三值不能解包成两值”的逻辑，不支持“某图效应量错误”。

## 3. 本目录脚本怎么运行

依赖：Python标准库；代码使用Python 3.9及以上的类型注解语法，实际测试环境记录在receipt，不把这个环境声称为作者论文环境。

```bash
# 在本子目录运行：公共文件与最小合同测试
python -m unittest discover -s tests -v
python scripts/preflight.py --puck-meta evidence/puck_meta.txt \
  --output validation/metadata_check.local.json

# 填写自己的真实设计表后运行；不要直接拿只有表头的模板当数据
python scripts/preflight.py --samples /path/to/real_samples.tsv \
  --output /path/to/design_check.json
```

脚本在输入缺列、空身份、重复样本、错误公共文件字节等情况下报错；对单阶段、某阶段动物ID过少、阶段嵌套于批次等给出提醒。通过检查不代表功效足够、配对正确、不存在混杂或空间独立性成立。一个section可能含多个肿瘤，脚本暴露而不简单禁止这一情况。

模板：[sample manifest](../templates/sample_manifest.tsv)、[cell metadata](../templates/cell_metadata.tsv)、[module coverage](../templates/module_coverage.tsv)。后两者为设计模板，不声称当前脚本已完成其全部校验。

## 4. 真正科学复现的四个里程碑

### A. 锁定材料与设计

取得可授权使用的终刊正文、完整补充表、具体代码归档和处理数据；记录哈希、下载时间与版本。将论文列出的Zenodo DOI解析到具体归档，并与GitHub固定提交比对。补齐animal→tumor→section→array→library，澄清实验性别范围与版本差异。

通过门槛：文件真实可读、输入对象语义清楚、每项分析独立单位明确、同名中间文件格式一致。未知参数不以常用值补齐。

### B. 重算最短关键链

先选择一个输入完整的肿瘤，以作者处理后的字符矩阵和表达／元数据走通树→fitness→邻域汇总，不立即从所有FASTQ启动。

原始代码和修复候选分目录，固定相同输入、版本与随机处理；记录预期叶子集合、实际叶子集合、矩阵缺失、分支长度、输出索引、分数尺度。发生解包或集合问题时，保存原始失败与修复依据，不静默改掉历史。

通过门槛：结果合同通过，并能解释原版／修复版差异；仍不能只凭退出码0宣布重现论文效应。

### C. 返回多样本和不确定性

按材料支持的动物、肿瘤和切片比较方向与区间，检查缺失、插补、树求解、邻域尺度、高低阈值及分母。单动物支路只提供动物内信息，不能由更多细胞升级为跨动物复验。

通过门槛：关键解释在合理分析集合下稳定；明确哪些不确定性来自测量、模型、样本和处理；不以选择最佳参数代替敏感性分析。

### D. 再进入来源、外部验证和机制

重建转移共识与原发映射，保存共享位点支持和无关病灶排除；核对跨物种、器官、平台和配对。共培养要追回终点细胞来源、重复层级、Cq处理及统计模型，区分整个体系效应和特定通路机制。

通过门槛：每条结论回到相应证据，不用一张总演进示意图代替全部环节。

## 5. 资源和环境不做虚假保证

本次没有测量真实科学流程的CPU/GPU时间、内存峰值或吞吐。ILP、快速NJ、神经网络注释和普通数据处理的依赖不同，按实际支路核实可选组件与许可。`requirements`安装成功不等于历史环境一致。

不得直接执行未知来源pickle或远程notebook。先审查输入和代码，明确权限与运行边界。用户此处授权的是把idea文档提交到指定仓库，不等于授权在其数据上启动昂贵分析。

## 6. 状态如何理解

“受阻”：重要来源、输入或调用链缺失，不能进行可归因的科学复现。

“材料冲突”：方法、代码、图注或实际接口存在需要对齐的差异。某行含冲突不表示整篇论文错误，也不一定表示已经在真实数据触发。

“材料完整但未执行”：仅当目标所需材料确实齐备才可使用；本次没有据此标记任何缺少矩阵的分析。

“已执行验证”：必须有该科学分析的实际运行、预定义结果检查和来源闭环。本目录没有满足这一状态的论文项目。
