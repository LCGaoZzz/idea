## 反向审查结果

**没有把常识包装成新发现。**这些设计和分析原则有广泛的方法学背景；本整理未做系统新颖性检索，不声称首次提出。价值在于将原则落到本文具体的取样、培养、指标及代码路径，而不是发明新名词。

**没有把相关与机制混为一谈。**空间相关、来源约束、培养体系干预和具体通路必要性分别标注；没有把整张LR候选网升级为机制网。

**没有删掉不方便的原文控制。**ED2的留出和模拟、ED5的共享基因检查、跨层非插补分支都保留，并说明它们实际验证的目标。

**没有预设任何项目都应关注同一细胞或同一生态位。**本文确实报告低氧、免疫和纤维化相关现象，但迁移原则用变量角色表达；新项目的具体候选必须由自身数据决定。

**没有默认追加昂贵技术。**最小动作从已有设计表、共同分析对象、样本级效应、分母审计和条件比较开始。只有问题已经无法由现有证据识别、且该问题会改变决策时，才讨论新的历史记录或交叉干预。

**没有将技术可运行性等同于科学有效性。**已确认的代码问题与终刊结论影响分开；测试通过范围见执行记录。

## 删除或改写的候选

“多关注空间异质性”太宽泛，改写为同阶段、同肿瘤内部的条件比较及样本级复验。

“多组学联合更好”没有给出识别增量，改写为历史信息必须独立于当前状态定义。

“低氧促进转移可推广到其他癌种”缺少跨项目证据，改写为候选因素的效应是否依赖背景、应比较哪些组合。

“插补会制造克隆所以不用插补”既忽略已有基准，也忽略原始数据缺失偏倚，改写为在共同对象上评估处理依赖。

“代码有bug所以论文不可信”越过了版本与运行链，改写为先界定受影响路径，再做原版／修复版对照。
