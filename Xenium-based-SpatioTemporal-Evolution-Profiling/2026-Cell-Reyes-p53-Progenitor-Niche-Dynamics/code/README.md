## 1. 两类代码严格分开

**作者源码**通过 [固定代码清单](../05-evidence/code_manifest.tsv)、[参数表](../05-evidence/parameters.tsv) 和[源码位置](../05-evidence/01-sources.md) 导航。本目录没有复制含大量图像输出的 Notebook，也没有声称已运行作者流程。

**本稿新编工具** `mixture_decomposition.py` 只对已经汇总的“独立动物×状态”表进行描述性代数分解。它不是作者 Figure S6D–F 的匹配代码，不估计直接因果效应，不推断单细胞转换，不提供 p 值、置信区间或中介分析。

## 2. 一个明确的问题，而不是一套虚构复现流程

总体程序均值变化，可能来自状态权重改变，也可能来自各状态中的程序均值改变。工具用对称分解将二者表示为精确相加的描述性项。

\[
\Delta=\bar Y_B-\bar Y_A=\Delta_{mix}+\Delta_{within}.
\]

\[
\Delta_{mix}=\sum_s(w_{Bs}-w_{As})(\mu_{As}+\mu_{Bs})/2,
\]

\[
\Delta_{within}=\sum_s(\mu_{Bs}-\mu_{As})(w_{As}+w_{Bs})/2.
\]

这不是唯一可能的分解；对称形式不指定哪一组为唯一参考。不同状态定义、采样范围和权重会改变估计目标。代数恒等式本身不能区分因果路径。

## 3. 输入合同

输入为制表符分隔文件（TSV），至少包含以下列，使用 [空白模板](animal_state.template.tsv)：

| 列 | 含义 | 要求 |
|---|---|---|
| `animal_id` | 真正的独立动物标识 | 不能用切片、区域或细胞 ID 代替；两组动物集合必须不相交 |
| `group` | 条件或阶段 | 文件仅包含命令指定的两组 |
| `state` | 事先确定的细胞状态/区间 | 定义在两组之间可比，不由待检验响应事后选择 |
| `n` | 该动物、该状态的实际观测细胞数量 | 正整数；真实零数量不写该行 |
| `mean` | 该动物、该状态中同一程序/量的均值 | 同一测量尺度，必须有限；允许合理的负分数 |

一行是一个动物×状态，不是一个细胞或一个切片。每个动物×状态只能出现一次。同一动物有多张切片时，须先明确组织覆盖与抽样目标，再显式汇总，不能通过重复行把一只动物变成多个重复。

工具需要**所选状态全集内完整的动物状态表**。只有在确知某行不存在代表该动物在该状态中实际观测数量为零时，才可使用 `--profiles-complete`。这个确认不能把面板未覆盖、区域未采样、输入丢失或过滤记录缺失变成零。

工具不能识别完全没有输入行的动物，必须先将输入动物清单与实验样本表对齐。只有一只动物的组也能计算描述性值，但不能因此进行群体推断。该工具针对非配对的独立组，不支持同一动物反复测量或配对设计。

## 4. 权重的具体定义

令动物 i 在所选状态内的比例为 \(p_{is}=n_{is}/\sum_s n_{is}\)。工具首先给予组内每只动物相同权重，再计算：

\[
w_{gs}=\frac{1}{N_g}\sum_{i\in g}p_{is},\qquad
c_{gs}=\frac{1}{N_g}\sum_{i\in g}p_{is}\mu_{is},\qquad
\mu_{gs}=c_{gs}/w_{gs}.
\]

由此组总体均值为每只动物总体均值的算术平均，而不是把所有细胞合并后的均值。组内某个状态的条件均值由上述贡献与权重之比计算，**不是所有动物该状态均值的简单平均**。这样保证分解与等动物权重总体目标一致。

这只防止细胞多的动物因数量而主导总体，不能自动解决取样区域偏差、阶段与批次混杂或状态测量错误。

## 5. 运行

只需 Python 标准库。采用现代类型注解，建议 Python 3.10 或更新；本次实际测试环境为 Python 3.13.5，未逐一测试其他版本。运行位置为本 idea 目录：

```bash
python code/mixture_decomposition.py \
  --input animal_state.tsv \
  --group-a early \
  --group-b late \
  --profiles-complete \
  --out results/early_vs_late.json
```

`animal_state.tsv` 必须由真实汇总数据填写；本目录的模板只有表头。程序默认拒绝覆盖已有结果文件，避免无意替换先前分析。错误会以非零退出码和明确消息返回。

## 6. 如何读取输出？

`delta_b_minus_a` 是等动物权重下 B−A 总体差异；`mixture_term` 和 `within_term` 是对称分解的两项；`state_terms` 显示各状态贡献；`identity_residual` 应只含浮点数误差。

`groups` 给出每组动物数、状态权重和条件均值。输出明确包含 `causal_effect=false`、`paper_reproduction=false` 及限制说明，不输出未经识别的生物学解释。

当总体差异很小而两项方向相反时，不要计算“机制贡献百分比”并过度解读；相互抵消的描述性项并不构成有稳定分母的比例归因。

## 7. 遇到 NO_COMMON_SUPPORT 时不要填零修复

如果某状态只在一组出现，另一组的状态内均值无法定义，程序会拒绝分解。把缺失均值写成零会制造不存在的生物学观测。

可以另行报告组特异状态的出现与比例；若科学问题要求限制到共同状态，必须明确记录去除了哪些状态、每只动物保留多少质量和数量，并说明估计目标已变为该子集。不能在不披露的情况下删除行后重新归一化。

同理，两组都含某状态也不等于协变量完全重叠，或所有动物都支持同状态比较。程序不会替代这些设计检查。
