# LungPCA：从肺癌前病变研究提炼可检验的时空演进idea

**核心问题：同一种环境因素的作用，是否取决于目标细胞状态、局部位置和疾病阶段？**

本目录将Peng等的文章故事、竞争解释、关键设计、主图1–7方法与代码、五条可迁移启发，以及“纯起始肿瘤克隆＋早中晚期小鼠Xenium”项目方案连成一个可独立阅读的研究档案。重点是帮助改变研究判断，而不是把算法列表拼成一个没有证据边界的流水线。

## 先读这段：文章到底带来了什么？

【P】作者把肺癌前病变中的异常肺泡中间状态与局部促炎环境联系，通过配对人类组织、细胞级空间测量、独立队列、小鼠培养、受体条件性删除与抗体干预逐层增加证据。论文并非只有空间相关性。[定位：Fig.1–7及正文对Fig.S8G–J的报告](https://pmc.ncbi.nlm.nih.gov/articles/PMC12980502/)

【I】它最有价值的结构不是一个可以换名套用的基因轴，而是：**状态、来源、环境和时间必须分别辨识，再用能区分竞争解释的实验把它们连接起来。** 细胞相邻不等于直接作用；状态连续不等于克隆谱系；更多终点对象不唯一代表更高形成率；模型间差异也不等于纯时间效应。

【H】迁移到三时期Xenium时，优先回答：在同一动物的可比较组织背景中，某状态是否具有特定局部环境？这种动物级关系是否随时间改变？若差异只由总体丰度、密度、批次或显示阈值解释，就收窄结论，而不是继续画确定的演进箭头。

## 五条启发的核心

1. 因素作用应按阶段与目标响应状态评价，而不只按终点丰度排名。
2. 局部富集必须相对于匹配背景机会率，并在独立动物/患者层面评价。
3. 相似状态不唯一决定历史，多种表达算法不等于多份独立证据。
4. 先拆清终点如何由形成、存活、生长、阈值和分母生成，再命名机制。
5. 样本内相对热点回答“哪里高”，不能直接回答样本间“总体增强多少”。

这些不是未经检索就宣称新颖的方法学发现。完整条件、反证与跨项目不确定性在第06章，不能只摘走上述五句话。

## 与用户项目最重要的对应与不对应

已知用户以相对纯的肿瘤克隆型造模，并在早、中、晚期取得多个Xenium样本。未知癌种、具体建模方式、间隔和每期独立动物数，本文不补设。

真实取材时间是优势，但不是细胞命运追踪；造模早期不是自动的癌前期；起始纯不等于后续所有变化都是遗传演化。首先建立“跨独立动物可重复、具有明确空间条件和替代解释检验的状态—环境转变”，再决定是否需要升级到干预或追踪。
