# 02｜研究设计、竞争解释与不可替代环节

## 1. 队列不是一个可以相加的“大样本数”

【P】以下规模取自论文 Results、Patient samples 和相关图注，未下载矩阵重计。TMA 是组织微阵列；core 是组织小柱，不能与病灶或患者混称。[论文定位：Fig.1A、Fig.5G–H、Patient samples](https://pmc.ncbi.nlm.nih.gov/articles/PMC12980502/)

| 证据模块 | 作者报告规模 | 测量对象 | 独立性与比较结构 |
|---|---|---|---|
| 人类 Visium | 25患者、56份组织、486,519 spots | 混合细胞的组织表达与位置 | 患者内病灶配对；spot 非独立患者 |
| 人类 snRNA-seq | 23患者、75份组织、401,635 nuclei | 核转录状态 | 来自相邻组织，不是与空间同一细胞的联合实测 |
| WES | 方法概述79份样本 | 样本层基因组变异 | 正常对照与非正常组织配对；不能一对一验证空间克隆 |
| Xenium发现 | 6患者、12份配对组织、4,598,777 cells | 细胞级靶向转录本与空间位置 | 6对癌前/浸润病灶；细胞数量不增加患者数 |
| Xenium独立验证 | 19患者、36病灶、8张TMA、188 cores、593,334 cells | 独立材料中的状态与邻域 | core 嵌套于病灶和患者 |
| 小鼠观察与扰动 | 多模型、不同终点、培养与组织读出 | 状态、病理负荷、免疫环境、类器官 | mouse、well、organoid、core 必须分开 |

【I】两处单位需要额外注意。第一，Patient samples 的概述把 Xenium 写为6 samples，而 Results/analysis 明确为6患者12组织；此处按后者描述发现队列，不擅自解释前者一定指玻片。第二，部分 TMA 生成文字出现“36 cores”，而总体清楚列36病灶188 cores；应保留原始登记核对，不重新发明换算关系。全文约540万细胞的总括数字不宜自行用不同纳入集合加总后替换。

## 2. 同患者配对：控制了背景，不控制历史

【P】作者在同一患者中比较癌前或微浸润病灶与 LUAD，并由病理复核各区域。取材流程按正常、癌前、浸润的顺序开展，以减少收集交叉污染。病理复核也改变了一个原先归类的病灶。[定位：Fig.1、Patient samples](https://pmc.ncbi.nlm.nih.gov/articles/PMC12980502/)

【I】操纵：无；测量：病理、表达、基因组及空间；控制：部分患者背景与取材流程。不可替代性：没有配对，就更难区分患者差异与阶段差异。上限：同步切除不提供哪一病灶先形成的直接记录；配对也不意味着必须共享克隆。

## 3. 克隆和状态的交叉：让表型不再包办来源

【P】空间 RNA-CNA、患者内参考及克隆树，与 WES 和病理互相对照。不同病例呈现不同的共享和分支结构。[定位：Fig.2、SpatialInferCNV analysis、Discussion](https://pmc.ncbi.nlm.nih.gov/articles/PMC12980502/)

【I】操纵：算法参考/分支选择而非生物过程；测量：表达推断的 CNA 特征与样本变异。不可替代性：没有来源相关信息，只能讲状态连续性，不能讨论克隆结构。仍需假设：RNA-CNA 足以分辨相关分支，参考区域合理，混合细胞没有主导结果，人工子树选择没有扭曲解释。

【H】重分析时分别保存完整连续 CNA、离散状态、reference barcodes、人工选择和最终树；独立变化参考集合，检查哪条历史关系稳定。此建议不是论文已完成的敏感性分析。

## 4. 细胞级空间验证：对“总量共变”施加约束

【P】Xenium 发现与独立 TMA 验证使用不同基因面板；分析以每个细胞为中心，考察80 μm内各状态数量/组成。发现中的 C15/C16 与验证中的 C4 是各自数据集的编号。[定位：Fig.5、Xenium data generation/analysis、邻域方法段](https://pmc.ncbi.nlm.nih.gov/articles/PMC12980502/)

【I】操纵：无；测量：同一细胞坐标系中的状态关系；对照：不同上皮中心、病理阶段与独立队列。不可替代性：没有直接细胞空间测量，难以将真实邻近与混合 spot/模型预测分开。仍需控制：密度、全局丰度、区域偏好、边界、面板缺失、分割及共享邻居。

独立队列提高跨材料一致性，但两个平台共有的基因识别规则可能仍有共有误差。不同聚类号不能直接合并；必须核对身份和表达特征。

## 5. 培养实验：有功能支持，但背景决定解释上限

【P】Fig.6H–K 从小鼠 AT2 来源建立 KAC-rich organoid 体系，使用体外诱导的 KRT8 报告；增加 IL-1β 或与间质巨噬细胞共培养后，数量及大小增加。培养方法包含内皮支持细胞、三维培养与生长支持条件，并记录直径大于100 μm的类器官；Fig.6J–K 每个点代表一个孔。[定位：Fig.6H–K、类器官培养方法段](https://pmc.ncbi.nlm.nih.gov/articles/PMC12980502/)

【I】操纵：候选信号或共培养环境；测量：可检测类器官数量/大小；对照：未处理培养条件。少了它，候选炎症可能仍是无功能伴随信号。它支持的是**在该培养背景中增加信号或细胞会改变读出**，不是脱离支持条件的普遍充分性。

必须保留四个限制：

1. 更快长过100 μm阈值，可能提高被计数数量，不必等于新增起始事件。
2. 存活、形成、扩增和状态进入都可能贡献终点，不能互换命名。
3. 体外诱导标签不自动证明处理前体内已经存在固定的同一细胞群。
4. 孔是图中统计点；来源动物与独立培养批次还需原始映射，孔数不自动等于生物重复数。

【H】最便宜的辨别是回看既有完整大小分布、阈值附近对象、已有早期图像和来源映射。不能从仅保留大类器官的汇总表恢复全部小对象。

## 6. 受体条件性删除：不能遗漏，也不能过度升级

【P】Animal models 描述 CCSP-Cre 相关肺上皮驱动 Kras 模型与 Il1r1 条件性删除；正文报告肿瘤及正常肺泡区域中 LAMP3+/KRT8+ 细胞相关读出下降。[定位：Fig.S8G–I 的正文报告、Animal models](https://pmc.ncbi.nlm.nih.gov/articles/PMC12980502/)

【I】操纵：该驱动模型内的受体功能；测量：肿瘤负荷与上皮标记；对照：相应无该删除的模型。少了这项证据，受体侧的功能解释明显更弱。但它不是 KAC 专一删除，不排除更早或更广谱上皮效应，且受体侧证据不能独自锁定唯一配体来源。不能将“有条件性删除”笼统概括为完整细胞特异机制已证实。

## 7. 干预窗口及另一模型阴性结果：情境差异不是纯时间实验

【P】Fig.7A–B 比较不同处理窗口下的单药、联用和对照；Fig.7F 显示不同终点的状态比例。正文对 Fig.S8J 的报告指出，同系移植的已建立肿瘤并未出现相同的抗 IL-1β 抑制生长结果。动物方法说明年龄/性别匹配、随机分组及盲法分析。[定位：Fig.7、Fig.S8J 正文、Animal models](https://pmc.ncbi.nlm.nih.gov/articles/PMC12980502/)

【I】操纵：系统性信号阻断及联用；测量：病理负荷、细胞组成和免疫环境。对照使完全无功能解释不够充分；另一模型提醒不能随意外推。但不同体系同时改变来源、组织位置、宿主环境及发展过程，所以只能稳妥说情境依赖。阴性也需效应区间和功效判断，不能将未显著当作零效应证明。

联用优于单药不自动等于药理协同；协同需要预先指定加性/乘性等尺度与交互检验。小鼠结果也不等于人类预防有效性。

## 8. 因果证据的分工表

| 证据 | 可以使哪类解释变弱 | 尚未排除 |
|---|---|---|
| 空间邻近 | 完全空间无关、仅远端样本均值 | 共同区域偏好、共同损伤、反向作用 |
| 增加候选信号 | 完全无功能的旁观者 | 支持细胞中介、存活/生长而非状态转换 |
| 受体删除 | 受体完全无功能贡献 | 非目标上皮效应、其他上游输入 |
| 系统性阻断 | 该模型内候选通路对终点完全无贡献 | 广泛免疫中介、非目标群体响应 |
| 时间或模型差异 | 所有情境作用恒定 | 情境变量具体是哪一个 |
| 状态降低且病灶降低 | 两个终点没有共变 | 状态是机制中介，还是与病灶共同改变 |

【I】必要性、条件性充分性、机制中介和相关一致性是不同命题。本整理只把证据放到它能约束的位置，不用“验证了”把它们压成一个总分。
