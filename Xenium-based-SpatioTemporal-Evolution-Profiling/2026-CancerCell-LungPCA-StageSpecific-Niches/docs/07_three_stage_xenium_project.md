# 07｜转化为“纯起始肿瘤克隆＋早中晚期小鼠Xenium”的完整idea

[返回入口](../README.md) · [上一章](06_transferable_insights.md) · [下一章：行动与决策](08_action_table_and_decisions.md)

> 本章全部分析设计为【H】迁移建议；不是Peng等已实施的流程，也不是针对用户数据已经完成的分析。未取得任何用户矩阵、坐标或样本表。这里保留问题结构，不预设新项目一定存在KAC、IL1B、稀有亚群、ECM机制或非细胞自主效应。

## 1. 已知背景、未知信息与不可跨越的语义边界

| 项目 | 当前已知 | 仍未知，不能自行补设 |
|---|---|---|
| 起始材料 | 相对纯的肿瘤克隆型，用于造模 | 单克隆验证方式、稳定性、起始状态分布 |
| 时间 | 初期、中期、末期取材 | 具体天数、阶段定义、是否同一动物反复取样 |
| 样本 | 各期多个样本，Xenium | 每期独立动物数、每动物切片数、性别/年龄/批次 |
| 模型 | 小鼠肿瘤模型 | 癌种、原位/异位/其他建模方式、宿主背景 |
| 平台 | Xenium | 面板版本、加测基因、分割版本、坐标及病理数据 |

**三个边界必须写进项目摘要。** 第一，真实取材时间不等于逐细胞命运追踪；第二，从肿瘤材料开始的造模早期不自动是正常组织的癌前期；第三，起始克隆纯度不能证明后续所有状态差异都是遗传亚克隆演化。不同时间点若来自不同动物，首先能估计的是群体分布随时间变化。

## 2. 核心科学问题与最低可支持结论

建议项目问题写为：

> 相对一致的肿瘤起始材料，如何在宿主组织和真实取材时间的共同约束下，形成不同肿瘤状态、细胞组成及空间组织？哪些状态—环境关系在独立动物中可重复，哪些差异可以由总体丰度、区域结构或技术因素解释？

最低可支持的目标不是“重建每个克隆的真实演化树”，而是一个**有明确证据来源的时空状态模型**。每条关系都注明来自时间比较、空间条件化关联、遗传信息或扰动；证据不足的箭头不画成确定转移。

预设的生物学对象可以改变：目标状态可在分析后由稳健证据确定，但发现与验证必须分开。不得在全数据中选最显著组合，再在相同数据上不加区分地称为验证。

## 3. 同一现象至少对应四类模型

假如中期某状态A增加并靠近环境B，不能立即得出B诱导A。

| 候选模型 | 可能预测 | 用现有数据先检查 |
|---|---|---|
| 时间相关状态重排 | 各动物在相似阶段出现相似状态分布 | 动物级阶段效应及留一稳定性 |
| 环境相关可塑性 | 同一来源/时间内，状态随局部环境而异 | 样本内、相似区域中的条件关联 |
| 选择性扩增 | 已有少量状态在后期增加，不必逐细胞转换 | 早期是否已检测到该状态；增殖/存活读出仅作线索 |
| 结构/技术解释 | 密度、取材区域、面板、批次足以解释差异 | 阶段—批次表、面积/区域分层、面板覆盖、分割QC |

“同一遗传来源出现不同状态”和“新遗传分支被选择”也需分开。仅有靶向表达面板时，不应将不确定RNA-CNA结果作为两者的裁判。

## 4. 第0阶段：在算任何生物差异前，先确认设计可辨识

建立[样本清单](../templates/sample_manifest.tsv)：animal、sample、section、coordinate_frame、stage、batch、panel是最低字段。一个动物多切片不增加动物数；同一sample不能被分配给多个动物。坐标域是实际可互为邻居的物理空间，不是任意文件名。

先运行[设计检查工具](../code/README.md)。它只检查元数据完整性、单位映射、是否存在阶段与批次完全混杂等问题，不做功效计算，也不认证生物学质量。

若每个阶段都有各自独占批次，则在把批次当作不受约束固定效应的模型中，阶段与批次不可分离。更复杂的整合算法不能从没有交叉的信息中创造辨识性。此时应报告限制，寻找真实技术桥接材料或独立验证，而不是声称“批次已消除”。

若动物重复取材，使用重复测量设计；若处死取材，按独立动物分析；若未知，先登记未知，不自动按独立处理。

## 5. 第1阶段：建立测量与排除的完整记录

保留计数层、细胞分割版本、转录本质量信息、组织mask、坐标单位、panel、病理标注及每阶段QC变化。表中缺失基因是未测量，不是零表达。

注释时区分：身份、状态、质量、恶性证据。以“缺少典型标记”为理由去掉细胞，可能去掉真正过渡状态，也可能合理去除低质量；必须用排除清单和组织图像判断，不能预设答案。

不盲目照搬本文5K的阈值或TMA阈值。先检查当前平台、面板和样本分布，再记录新选择的依据。原始分割带来的细胞数量差异与生物组成变化需要分开。

第一份结果应是动物级QC和纳入流程图，而不是UMAP。

## 6. 第2阶段：确定可跨样本比较的状态与程序

可以先按大谱系识别宿主与肿瘤相关群体，再建立肿瘤内部状态或连续程序。不要强行给每个细胞一个唯一离散状态；对相近程序保存完整分数、第一第二分数差及不确定标签。

跨时间一致命名应依靠可比较特征，而不是各样本相同的cluster编号。不同面板先检查共同可测特征和评分覆盖率；覆盖差时，应缩窄结论或分面板验证，不用插补伪造共同测量。

状态定义与响应验证尽量使用不同特征。若用一组炎症基因定义状态，又用同组基因证明它炎症更高，这是定义的一部分，不是独立验证。候选程序可从探索集中学习，但验证集/留一动物应用时不能重新按结果命名。

## 7. 第3阶段：同时描述数量、组成和组织位置

对每个动物保存：各状态数量、保留细胞总量、组织面积（可靠可得时）、病理区域比例、切片数与采样范围。数量增加、比例增加和单位面积密度增加是三个问题。

肿瘤边界、血管邻近、坏死边缘等空间变量只有在病理支持、技术可靠且与问题相关时才纳入；不预设所有项目都以边界或ECM为主。边界是人工或算法定义时，要保存定义与版本，并用独立信息评估误差。

可以制作空间分层表，但不能因某位置最显著才事后把它定义成主分析区域。有效面积和组织空腔应显式处理，特别是不同阶段组织结构变化很大时。

## 8. 第4阶段：中心条件化邻域，而非全组织的平均互作图

选定少量有生物与数据依据的目标中心状态A及候选环境B。在同一物理坐标域内建立邻域，记录计数、比例和有效面积。半径、是否排除自身、跨core规则均写入[决策配置](../templates/analysis_decisions.json)，没有论文之外的隐藏默认值。

设计的核心是对照：在同一动物、相近区域与密度中，寻找可比较的中心状态或背景位置。每只动物先估计一个差异，而不是将所有邻域混在一起增加n。例如：

```text
Δanimal = 目标A中心的B邻域指标均值
          − 匹配背景中心的B邻域指标均值
```

这只是一个建议的描述效应，不是已经选择的最优统计模型。样本间差异、匹配权重、区域权重和不确定性都需预先说明。没有匹配背景的动物，该对比应为不可估计，不填0；同时检查这种缺失是否与阶段相关。

空间置换也要有明确零假设。全片随机打乱会破坏正常组织结构，不能将其显著性自动解释为直接互作。要保留哪些结构，取决于想排除的是总体丰度解释、区域偏好解释还是更细粒度的局部关系。

## 9. 第5阶段：真实时间比较与两个不同估计目标

**目标A：总体阶段变化。** 问“随着取材时间变化，整个已采样组织的状态/环境如何改变？”病变大小和结构可能是变化的一部分。

**目标B：相似组织条件下的阶段变化。** 问“在可比较区域、密度或目标状态中，阶段是否仍相关？”这需要重叠样本范围，并回答一个条件化问题。

不能把两者混在一个回归表里声称同一因果结论。病变大小、坏死、免疫环境可能是混杂、效应修饰或中介，角色取决于问题。先画候选因果图，说明为什么调整每个变量。

三个时期先使用有限且可证伪的对比：持续升高/降低、中期高值、早期限定或结构条件化变化。不靠三个阶段估计唯一连续转移速率，不把伪时间当实际时间。阶段×状态或阶段×环境交互可作关联模型，但不能直接称为干预效应。

首先报告动物级效应量、区间、方向一致性和留一动物结果，再看p值。小样本不强行容纳大量协变量；若独立动物不足，描述结果并保留不确定性，不能用更多细胞掩盖这一点。

## 10. 技术复用与生物外推的分叉

| 可以优先迁移 | 不应默认迁移 |
|---|---|
| 清晰的样本层级和来源标记 | 本文KAC/IL1B就是新项目主轴 |
| 状态条件化、背景匹配的局部比较 | 80 μm一定适合新组织 |
| 程序与坐标联合解释 | 最高程序标签等于真实固定亚型 |
| 真实时间的动物级比较 | 三个时间点提供了克隆谱系真值 |
| 连续尺度与相对热点分开 | 独立色阶可以用于总量比较 |
| 阳性和阴性都能改变决策的假说 | 观察性空间关联已经确定作用方向 |

## 11. 候选结果达到什么条件，才值得升级实验？

优先升级跨独立动物方向稳定、不是阶段—批次完全混杂、在合理尺度/连续读出中保持、且与独立目标响应相容的关系。不要把“显著p值最多”当成升级条件。

下一步只解决最关键的未辨识问题：若缺的是功能贡献，改变候选环境并读目标响应；若缺的是作用对象，区分来源侧与响应侧；若结论必须是祖先—后代，增加独立追踪。具体实验方案需结合实际模型、伦理和实验条件确定，这里不凭未知背景提供固定试剂或剂量。

一个可发表图故事可以是：设计与QC→跨动物状态变化→组织结构→条件化邻域→阶段限定关系→竞争解释检验→有限箭头的工作模型。它是拟议写作结构，不是已生成七张结果图。

## 12. 预先约定何时收窄结论

匹配后局部效应消失：改讲总体组成变化；只由一个动物驱动：降为待验证观察；共同尺度下不再有变化：回到显示/评分解释；无来源证据：不写克隆演化；跨阶段缺乏可比状态：不写效应消失；未扰动：不写直接机制。

最重要的输出不是一张箭头最多的演进图，而是一张**每条箭头都有证据类型、替代解释与下一步辨别动作的模型图**。
