## 1. 这份内容是什么

这是一份基于论文与官方源码的完整阅读型 idea，包括故事、实验设计、数学方法、八条延伸见解、可证伪研究方案和轻量分析代码。它延续此前的论文重建资料，但不把此前「材料清单校验通过」升级为科学复现完成。

原重建包记录 16 个分析目标、91 条参数记录和 20 条来源记录，其中许多目标仍受缺失材料阻断。这些数字描述重建工作量，不是成功运行数。本目录不重复发布一套会误导读者的“全部已完成”重建 manifest。

## 4. 论文参数、公共默认和本项目演示参数分开

论文 exatecan 主设计的 top 3、每骨架 1,000 条，与 Fig. 1c 的首轮 500/后续 1,500 条不同；公开 NISE 示例的 35 轮、每骨架 64 条也不同。应按分析分支分别记录，而不是强行统一。

论文 apixaban 初筛中的双 RMSD < 2.0 Å 不自动等于正式 NISE 和最终筛选的统一阈值。组合分数、埋藏定义及最终排序公式仍需 SI 与分析代码确认。

`configs/paper_profiles.json` 保存这种不确定性；未知值为 null 或明确文本状态。本项目演示门槛 2.5 Å / 0.8 仅为测试输入，不作为论文已恢复配置。

## 5. 主要源码风险清单

| 观察 | 风险 | 本目录处理 |
|---|---|---|
| debug 可放松过滤 | 测试输出被误写为科学成功 | 筛选器拒绝 debug 记录 |
| pLDDT 存在 0–100 与 0–1 | 阈值错位 | 必须声明尺度 |
| NLL 使用 log10 | 与自然对数或自由能混用 | 显式命名概率差值 |
| 空原子约束 | 以为已检查特定官能团 | 缺少实际几何证据不补成通过 |
| 历史字段名称 | 把 Boltz 输出误认为 Rosetta | 文档记录字段语义 |
| 只检查文件存在 | 解析或科学失败被掩盖 | 分开进程、格式与科学状态 |
| pickle 输出 | 不可信反序列化 | 本分析使用 CSV/JSON，不自动加载 pickle |
| 子模块更新 | 方法行为漂移 | 固定父仓库及子模块，不使用 --remote |

这些是读取范围内的观察，不是对整个上游项目做过全面安全或运行审计。

## 6. 真实复现的下一步应是什么

先取得 SI 与设计/分析档案，确认每个图的输入和脚本；再匹配论文历史参数与固定代码版本；然后进行最小真实运行和独立结果检查。不要先替换成另一套 API，再把新结果叫作历史复现。

每次运行应保存输入、权重与代码哈希，完整参数和随机性配置，日志，逐轮候选谱系，失败原因以及结果检查。推理顺利不等于结合成立，结构比对通过也不等于功能保护。

## 7. 关于前瞻性与证伪

本文将独立评估、状态对比与功能终点作为有根据的研究假设，但没有伪造新候选或性能增益。一个可靠的后续结果可以是「没有改善」「只对部分拓扑有效」或「原始内部评分出现失配」。研究价值来自清楚地限定何时成立，而不是提前承诺更高命中率。
