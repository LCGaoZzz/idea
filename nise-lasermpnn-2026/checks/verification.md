这些测试不是完备数学证明，不覆盖任意 PDB 的化学映射，也不提供真实数据下的可辨识性、置信区间或外部泛化证明。

## 3. 合成示例的实际数值

所有浓度单位统一为 nM，随机种子为 20260911。数据加入了明确的合成噪声，因此拟合值不应恰好等于真值。

| 演示 | 真值 | 实际输出 |
|---|---|---|
| 直接结合 Kd | 3.5 | 3.50369614517768 |
| 竞争结合示踪物 Kd | 1.4 | 1.4000493079933822 |
| 竞争物 Kd | 0.23 | 0.22971181756295864 |
| 仅将配体平移 3 Å | 配体误差 3 Å | 3.0000000000000013 Å |
| 整个复合物共同刚体变换 | 两种误差均为 0 | 浮点误差量级约 10⁻¹⁵ Å |

程序不以独立配体对齐消除错误位置。`chemical_mapping_checked_here=false` 明确说明原子化学对应关系不是这个坐标函数证明的。

## 4. 论文中心值的独立算术

demo 中另有 `published_point_estimates_derived_math_not_refit` 分区，以作者公布的 120、8.0、7.4、1.2 nM 中心值计算突变循环。严格独立预期双突变 Kd 为 0.4933333333333337 nM；在**示意温度** 298.15 K 下，耦合项为 +0.5266549883535921 kcal/mol。

这些结果是代数推导，不是原始实验重拟合，不包含误差传播或显著性检验。温度也不是本次恢复的实验条件。详见[第 7 章](../docs/07_statistics.md)。Wilson 区间同样仅是明确假设下的描述性计算。

## 5. 文件身份与复查方式

[verification.json](verification.json) 保存所有已测脚本和测试文件的字节数、SHA-256 及 Git blob SHA-1。与待提交树 `517a0fc8e780c51c33d7cc61433826d3fea72c2a` 的对应对象逐项核对一致。

Git blob SHA-1 计算的是 `blob <bytes>\0` 头加文件内容；它不是单纯文件 SHA-1。SHA-256 则针对文件原始字节。保存两者便于同时核对下载副本与 Git 对象。

重新运行时应使用新的输出目录；程序拒绝覆盖既有目录。不同数值库或硬件可能带来微小浮点差异，先检查守恒与误差界限，不要求日志或所有小数位完全一致。
