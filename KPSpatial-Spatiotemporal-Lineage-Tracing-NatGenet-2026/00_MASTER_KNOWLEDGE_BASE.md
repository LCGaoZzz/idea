# 00｜Master Knowledge Base

## 1. 文章真正解决的核心矛盾

空间肿瘤组学经常看到一种模式：某种癌细胞状态、缺氧、髓系细胞、CAF 和 ECM 在同一区域共同出现。但这种空间共现至少有四种竞争解释：

1. **克隆历史主导**：同一亚克隆扩增并携带相似状态；
2. **局部环境诱导**：不同亲缘分支进入同一环境后趋同；
3. **共同混杂因素**：肿瘤大小、血供、几何结构等同时驱动多个读出；
4. **双向反馈**：亚克隆扩增改变环境，环境又反过来塑造状态与选择。

本文的设计价值，是把“谱系历史”“当前表达状态”“空间位置”变成三种不同信息来源，从而约束这些解释。

## 2. 研究设计的证据链

### 2.1 表达层

Slide-seq/Slide-tags 给出空间表达和细胞/spot 坐标。表达层回答：某类肿瘤状态、局部程序和 TME 构成在哪里出现。

### 2.2 谱系层

基于可编辑 target sites、intBC/allele 状态和 Cassiopeia 构建字符矩阵，再重建谱系树。谱系层回答：哪些观测共享编辑历史，哪些区域可能属于同一演化分支。

### 2.3 空间层

空间图用于社区、邻域、插补及区域分析。必须注意：当空间位置同时参与谱系缺失值插补，后续再用树解释空间聚集时，历史证据与空间证据已不完全独立。

### 2.4 转移层

转移灶的编辑状态可形成共识，再与原发肿瘤中的观测比较，以定位与转移灶亲缘更近的原发区域。这个过程支持“亲缘关联”，但不直接给出细胞离开原发的准确日期、迁移路线或全部细胞的转移能力。

## 3. 空间社区到底怎么计算

这篇论文的空间社区不是“先统计每个细胞周围各种 cell type 的比例，再对组成向量聚类”。其核心是 **空间共变基因程序**。

主要逻辑：

1. 在每个样本上建立空间邻接图；
2. 用 Hotspot 寻找具有空间自相关的基因；
3. 在样本内把空间共变基因组织成模块；
4. 跨样本根据模块基因重叠/Jaccard 关系构建共识模块；
5. 对每个 spot/细胞计算这些共识模块的表达分数；
6. 需要离散展示时，可取最高分模块作为社区标签，但原始连续分数更重要。

公开方法记录包含：20-neighbor 空间图、空间自相关基因 FDR 0.01、模块至少 50 基因，以及 11 个跨样本共识集合。

审读代码中的社区打分步骤包括：按样本 normalize、`log1p`、`scale`，然后 `score_genes(..., ctrl_size=100, n_bins=30)`。

### 3.1 解释时最容易犯的错误

- 社区不是一种 cell type；
- 某社区升高可能来自组成变化，也可能来自同一细胞类型内部状态变化；
- `argmax` 离散标签会掩盖第一、第二高分几乎并列的区域；
- 所有样本共同参与模块发现后，再在这些样本上评分，不等于真正的跨动物独立验证。

## 4. 谱系字符矩阵与空间插补

字符矩阵的观测单元来自编辑 target sites。典型状态包含：未编辑、特定 indel、缺失及混合状态。

公开代码可见的插补逻辑：

- 对缺失状态寻找空间邻居；
- 收集邻居对该字符的有效状态；
- 用多数票选择候选状态；
- 要求一定 vote concordance；
- 可设置空间半径、hop 数和迭代轮数；
- 通常不把 0（未编辑）当作可插补突变状态。

### 4.1 统计含义

空间插补相当于引入先验：“空间相近的观测更可能共享谱系状态”。如果之后使用同一字符矩阵重建树，再证明谱系和空间高度一致，二者存在结构性依赖。因此：

- 必须保留插补前/后两套结果；
- 关键空间结论要在未插补或低插补子集上做敏感性分析；
- 不应把插补提高后的空间聚集完全视为独立生物学发现。

## 5. Tree fitness 与 plasticity

论文把树形信息用于扩增/适应度相关分析。审读固定 Cassiopeia 提交后发现，`LBIJungle` 包装层实际把 `mean_fitness` 写入树的 `fitness` 属性，底层又把 `mean_fitness` 与 `polarizer` 作为不同计算分支。

因此在没有最终环境闭合前，最稳妥的表述是：

> 这是“树推断的 fitness 代理”，不能仅凭接口名称直接把所有数值解释成教科书式标准 LBI。

对于 plasticity，也要区分：

- 树上后代状态多样性；
- 当前空间区域中的表达多样性；
- 真正细胞状态转换率。

前两者可以作为 proxy，但都不是连续时间下直接观测的状态跃迁率。

## 6. CNV 与谱系结构的一致性

论文使用 inferCNV 相关标签去验证谱系结构与拷贝数差异是否一致。公开脚本对每个叶子寻找所谓“最近邻”，计算标签一致性 purity，再通过随机置换标签构建零分布。

本次审计确认：

```python
if _score > nn_score:
    significance += 1
return nn_score, significance / B
```

严格 `>` 会把与观测值相等的置换排除在上尾之外。

在离散统计量中，特别当 purity 经常达到 1 时，并列值很多。用严格大于会系统性压低 P 值，甚至让没有信息的情况得到 `P=0`。

合成反例：四叶星形树所有标签相同，观测 purity=1，所有置换也都是 1，正确上尾 P=1，但原函数返回 P=0。

另一个四叶二叉树例子中，姐妹叶分别同标签时，6 个不同平衡排列中有 2 个达到同样 purity=1，所以精确上尾 P=2/6=1/3，而原函数仍返回 0。

### 6.1 正确修复原则

- 使用包含并列值的上尾：`T_perm >= T_obs`；
- 若是 Monte Carlo 置换，避免无依据的零 P 值，可采用 `(b+1)/(B+1)`；
- 更关键的是先定义正确的 exchangeability：哪些标签允许互换、是否按动物/肿瘤分层、是否保持簇大小。

局部反例证明的是**实现存在统计合同问题**，不是已经证明论文每一个真实 P 值都会变成不显著。

## 7. TME、缺氧与扩增亚克隆

论文把扩增亚克隆与低氧、免疫抑制和纤维化环境联系起来。解释时应分开三类量：

1. **cell-type composition**：局部是否有更多 CAF/髓系；
2. **cell-intrinsic state**：同一细胞类型内部是否真的改变程序；
3. **组织级环境**：低氧、ECM、几何、血供等空间变量。

一个 ECM program 高的区域可能只是成纤维细胞比例更高，并不等于每个 fibroblast 都上调同样程序。相反，同一组成下程序改变才更接近 cell-state reprogramming。

## 8. 转移来源与跨切层匹配

共享编辑状态可以支持原发和转移灶之间的亲缘联系，但不能自动升级成完整三维组织配准。

把离散的原发支持点变成连续“转移来源区域”时，还会经过栅格化、平滑、阈值和区域分割。最终区域的几何连续性部分来自算法，因此应保存：

- 原始 allele distance；
- 支持 UMI/缺失率；
- 原始命中点；
- 平滑结果；
- 阈值后 mask；
- 参数敏感性。

三种“转移能力”必须分开：

- 与已观测转移灶有亲缘关系；
- 表达转移相关程序；
- 功能上具有更高转移能力。

三者相关并不意味着可以互相替代。

## 9. 样本层级与伪重复

公开 `puck_meta.txt` 中：

- Slide-seq 阵列 44；
- Slide-tags 阵列 5；
- 不同 Mouse ID 24；
- 5 个 Slide-tags 阵列都标记为 SPC-11。

因此，5 个阵列不是 5 个独立动物；同一动物的多个切片/阵列/ROI 也不能在统计上自动视为独立生物重复。

建议所有分析显式维护层级：

`animal -> tumor -> section/array -> ROI -> cell/spot`

混合模型或层级 bootstrap 可以尊重已有重复结构，但不能创造不存在的动物重复。

## 10. 本文对空间肿瘤学最普适的启发

### 启发一：把历史与状态分开

空间上相似的状态不等于共同祖先；共同祖先也不保证当前状态相同。

### 启发二：用“反例区域”增强机制判别力

比继续收集“低氧高、免疫低”的正相关区域更有价值的，是寻找：

- 低氧强但仍保留免疫活性的区域；
- ECM 高但髓系抑制弱的区域；
- 相同 cell composition 下肿瘤状态不同的区域；
- 相同肿瘤状态下环境完全不同的区域。

这些反例更能区分“环境诱导”“克隆历史”“共同混杂”和“双向反馈”。

### 启发三：连续分数优先于硬标签

不论社区、低氧、ECM、fitness 还是 plasticity，硬阈值或 argmax 主要用于展示。科学分析应保留连续值、置信区间、第二最佳状态和敏感性。

### 启发四：跨样本共识不等于外部验证

真正外部验证应在未参与特征发现的动物/患者上测试已经冻结的基因集、评分函数和阈值。
