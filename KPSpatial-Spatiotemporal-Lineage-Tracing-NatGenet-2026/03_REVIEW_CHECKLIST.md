# 03｜Independent Review Checklist

用于 Fable 或其他独立模型审阅本知识库。

## 必须先核实的边界

- 当前没有证明固定 GitHub 提交就是终刊所有图的最终运行环境；
- 当前没有整篇端到端复现；
- 局部代码反例不能自动升级为论文主结论无效；
- 缺失材料应标记为 unknown，不应写成“作者没做”。

## 第一优先级核查

### 1. CNV P 值

重新检查公开脚本中严格 `>` 的置换尾部；枚举微型树所有标签排列；比较包含并列值的精确上尾。然后再对真实树和 CNV 标签重算。不能把合成树的 P=1/3 当成论文某一行的真实 P 值。

### 2. Fitness 输出语义

追踪：论文术语 -> `LBIJungle` -> 实际 Cassiopeia 版本 -> 导出字段 -> 后续归一化。确认 `mean_fitness` 与标准 LBI 的关系，不要用类名代替算法定义。

### 3. 分组剪树

核对 `grouping_var/tumor_id` 分支是否真实可达；确认集合差方向；比较修复前后真实树的 fitness 排名和高低组标签。

### 4. 独立重复

按 `animal -> tumor -> array -> ROI -> cell` 重建样本表。确认 5 个 Slide-tags 阵列来自 SPC-11 这一局部事实，但不要扩大为整篇研究只有一只动物。

## 第二优先级

- Hotspot 共识模块阈值边界；
- 插补活动参数 vs helper 默认值；
- 空间邻域半径、坐标单位；
- PBMA 样本数量文本矛盾；
- COL1A2 / Col2a1 集合差异；
- 转移来源区域的平滑与阈值敏感性；
- ligand-receptor score 是否真的对应 P 值或仅是排名指标。

## 审阅输出建议

每项给：

- 成立 / 部分成立 / 不成立 / 无法判断；
- 证据来源；
- 是否属于论文事实、代码事实、实际执行结果、推断或建议；
- 严重度；
- 对科学结论的潜在影响；
- 当前是否已有足够材料判断。

## 明确尚未完成

- 完整终刊 Results 与所有主图逐 panel 核对；
- 全部 notebooks 审计；
- 最终 Zenodo 代码归档与 GitHub diff；
- 原始 AnnData、allele table、真实树获取；
- 修复前后真实结果差异；
- 共培养统计重算；
- 外部队列完整 sample manifest 追踪。
