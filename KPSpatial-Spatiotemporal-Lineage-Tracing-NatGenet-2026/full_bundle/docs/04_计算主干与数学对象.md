# 04｜计算主干：输入、输出、算法与数学对象

## 两条原始测量支路不能合并成一条表达流程

```text
空间表达 FASTQ → counts / QC / 坐标 → 细胞类型与基因社区分数 ─┐
                                                          ├→ 亲缘 × 状态 × 位置
谱系 FASTQ → allele table → character matrix → 树 / 枝长 ─┘
                              ↑                     ↓
                      可选空间插补             fitness / plasticity
                                                    ↓
                              邻域组成 / 同类型 DE / LR / 转移相关区域
                                                    ↓
                                  组织学、蛋白、共培养和外部数据
```

[I] 相同的 `cellBC` 或 AnnData 索引只是连接键，不意味着所有矩阵都是同一种观测。特别要分别记录表达 UMI、谱系 UMI、细胞／spot 和映射成功状态。

## 表达层

[P] 处理分为 Slide-seq 与 Slide-tags，前者空间捕获、后者空间映射单核；表达参考为小鼠 mm10。补充方法给出平台读段、低支持过滤、归一化、log 和缩放，以及 Slide-tags 的背景与异常文库处理。[P2–P3]

[C] `score_consensus_hotspot.py` 逐样本归一化到中位文库量，过滤少量细胞检测的基因，然后 log1p、scale、为已有共识基因集打分。不是每一支路都固定归一化到 10,000，也不能把 `adata.raw` 的名字视为原始 counts 的保证。[C6–C7]

[H] 必须记录 `X`、`raw`、`layers['counts']` 的语义以及每次归一化的输入。重复对已 log 的矩阵做 library-size normalization 是另一种运算，不是无害的“标准处理”。跨物种比较需先固定基因命名和同源映射，不能简单对整个表统一大小写。

## 谱系层：三个状态必须区别对待

[C] 编辑矩阵中，缺失通常编码为 -1，未编辑编码为 0；多状态可用 tuple 表示。`cellBC × intBC × allele` 支持表与 `cell/spot × character` 矩阵不是同一个分辨率。某些分支保留冲突状态，另一些分支选择最常见状态；转换策略需要逐分析指定。[C2–C3]

[I] 将缺失当作未编辑会凭空加入祖先证据；将混合状态全部当作测序错误可能丢掉真实混合细胞信息；将一个状态集合压成多数状态则会牺牲少数谱系。作者使用不同策略，是因为单细胞和混合空间观测的误差机制不同，不是随意改参数。

## 空间插补

[C] 已读函数基于空间图遍历限定 hops，收集非缺失状态，返回众数、一致性和支持票数。tuple 中的各状态可分别投票。因此“票数”未必等于独立细胞数，必须看混合状态的计票方式。[C3]

[I] 可抽象为：对缺失的字符 j，从允许的邻域 N(i) 收集可见状态；以众数为候选，以众数票数／全部有效票数为一致性。只有支持数和一致性同时达到目标分支要求时才接受。这是方法解释，不是替代作者实际参数。

[H] 保存一张逐状态插补账本：受体 ID、字符、原缺失标记、供体 ID、供体原始／插补来源、图距离、物理距离、轮次、一致性和支持数。多轮插补会让上一轮预测成为下一轮供体，不能把传播后的票数都视为新的独立证据。必须同时保留非插补矩阵。

## 混合状态距离的一个重要数学性质

[P/C] 适应混合观测的策略包含候选状态之间的最小联接比较；罕见编辑通过先验进入权重。不同平台使用不同的树求解组合。[P2；C2]

[I] 对无权重的直观例子，设相同编辑距离为 0、未编辑与编辑不同为 1、两个不同编辑为 2。用状态集合 A={a}、B={a,b}、C={b}，并取任意候选对中的最小距离，则 d(A,B)=0，d(B,C)=0，而 d(A,C)=2。这违反三角不等式，也使不同集合可能距离为零。[T1]

**这不是“算法因此不合法”的证明。** 它说明这个量应叫特定观测模型下的不相似度，而不能无条件解释为真实进化距离。需要用混合比例、缺失率和已知真树的模拟来评价其影响。加权距离公式的排版读取不完整，本包没有按乱码重建作者完整加权公式。

## 树与枝长不是同一个推断

[P] Slide-tags 的树与不可逆编辑模式相结合，可以使用 `IIDExponentialMLE` 估计枝长；Slide-seq 缺失和混合更明显，作者采用有编辑为 1、无编辑为 0 的保守枝长设置。[P2：PDF 第17页]

[I] 拓扑给出亲缘约束；枝长还引入模型及时间尺度假设。用 0/1 编辑边计算的分数不能直接解释成天数或每小时净增长率。不同求解器、重复状态压缩与零突变边折叠都会改变后续树形统计。

## Fitness：先核实变量身份，再解释生物学

[C] KPSpatial 将 `LBIJungle()` 写入树的 `fitness` 属性，随后取叶子分数除以最大值。本次固定的 Cassiopeia 包装层实际导出 `res_df.mean_fitness`，更下层对 mean_fitness 和 polarizer 使用不同计算分支。[C1；C9–C11]

[I] 因而本包采用“树推断 fitness 代理”这一称呼，不将标准 LBI 的积分表达式冒充此实现的实际数学定义。作为背景，标准局部分枝类指标衡量经过距离衰减的附近树分枝量；而后验 fitness 推断属于带额外演化假设的不同对象。确认名称—实现—论文环境的映射，是解释结果之前的必需步骤。[B2；C9–C11]

[I] 即使导出语义完全明确，树形也同时受到扩增、死亡、取样覆盖和记录器缺失影响。每个肿瘤内部的相对分数不是跨肿瘤的绝对适应度单位；对有负值的分数除以最大值，也不保证范围为 0–1。负值条件例见审计，不声称作者实际数值出现该情形。

## Plasticity：亲缘近邻的状态差异

[P] Slide-tags 利用细胞状态在树上的小简约法得分并按子树规模归一化；Slide-seq 使用谱系近邻的 community score 差异。后者公式已通过 PDF 第17页图像核验：[P2]

\[
P_{L2}(i)=\frac{1}{|N_T(i)|}\sum_{k\in N_T(i)}\|C_i-C_k\|_2.
\]

这里 C_i 是 spot 的社区分数向量，N_T 是谱系近邻；不是空间 KNN。L2 范数不是平方范数。

[I] 该数衡量近亲观测的表达程序不一致，不等于实际观察到的状态转换次数或速率。若 C 的某维缩放一倍，那一维对欧氏距离的贡献会改变；同一个 spot 多了 CAF 成分也可能增大差异，而不需要癌细胞真的变换状态。应报告不同模块标准化、树扰动、单核注释及组成控制下的敏感性。

## 邻域组成与 DE

[I] 在半径邻域内，细胞类型比例可以写为 p_ik=n_ik/n_i。再除以阵列背景比例 p_.k 得到富集比 E_ik=p_ik/p_.k。相同的邻域计数可因背景分母变化产生不同富集，因此必须保留原始计数和有效组织面积。富集比、细胞密度和细胞内表达是三种不同结果。

[P/C] 作者使用平台相关的物理半径／最近邻策略，并分析扩增邻域中髓系和成纤维表达；相关参数和代码接口差异见参数与审计章节。[P2–P3；C5–C7]

[H] 同类型 DE 至少需要区分“同一细胞亚型程序改变”和“合并大类中亚型比例改变”。建议同时给出细分亚型组成、同亚型内效应及动物／肿瘤层汇总，避免仅用所有细胞的 t 检验承担跨动物推断。
